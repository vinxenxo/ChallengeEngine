# C11-C v2.0.3 — Godot Shader Hotfix + Artifact Cleanup

## Scope

This overlay is presentation/tooling-only. It does not modify `core/`, simulation math, `SimulationResult`, deterministic engine RNG, C7 audio contracts, or the C11-B frozen semantic baseline.

## Godot parse hotfix

The five C11-C visual-loop prototypes now consume `C11CEditorialAnimator.gd` only through an explicitly named `preload()` constant:

- `EDITORIAL_ANIMATOR_SCRIPT`
- `_header_animator: RefCounted`

The common animator no longer registers a global `class_name`; this avoids class-registration/order ambiguity and removes the exact failure mode:

`Identifier "C11CEditorialAnimatorClass" not declared in the current scope.`

The same fix is applied consistently to Geometric Waves, Fractal Bloom, Sacred Symmetry, Living Particles and Invisible Forces.

## Artifact cleanup

New tool:

```powershell
.	ools\prototypes\c11c_bulk\clean_c11c_artifacts.ps1
```

The default mode is **DRY-RUN**. It only proposes removal of regenerable rendered media under `artifacts\prototypes` and all contents of `artifacts\scratch`.

Protected roots are never touched:

- `artifacts\legacy`
- `artifacts\qa`
- `artifacts
egression`
- `artifacts
eleases`
- `artifacts\production`
- `artifacts	ests`

JSON/TXT/MD/SHA256 sidecars under prototype folders are retained as metadata/evidence. To actually purge the disposable media after inspecting the dry-run:

```powershell
.	ools\prototypes\c11c_bulk\clean_c11c_artifacts.ps1 -Apply
```

This intentionally does not try to be a blind "delete old files" command: the project has historical QA/regression evidence whose deletion would be unsafe.


## v2.0.3 corrective patch

This patch supersedes v2.0.2. It fixes the shader identifier observed in the local Invisible Forces render: the shader defines `IF_TAU`, so the color-phase expression now uses `IF_TAU` rather than the undefined `C11C_TAU`.

It also replaces the v2.0.2 cleanup script with a parser-safe PowerShell parameter block and explicitly preserves `artifacts/prototypes/c11c_review_assets`.
