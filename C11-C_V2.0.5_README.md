# C11-C v2.0.5 — Bulk / Fractal Shader / Artifact Reset Hotfix

Overlay on top of C11-C v2.0.4.

## Fixes

- Fixes Fractal Bloom shader uniforms `color_phase` and `color_diversity`, which were used but undeclared.
- Replaces style-review checks that incorrectly relied on stale `$LASTEXITCODE` after PowerShell scripts; PowerShell script success is checked with `$?`. The cleaner uses `return`, not `exit`, when called as a child `.ps1`.
- Adds `-ResetC11C` to `clean_c11c_artifacts.ps1` for an explicit clean rebuild of the regenerable C11-C artifact workspace.
- `-ResetC11C` removes only `artifacts\prototypes\c11c_*` and the contents of `artifacts\scratch`; it never touches `legacy`, `qa`, `regression`, `releases`, `production`, or `tests`.
- The style-review orchestrator now uses the C11-C reset by default, so repeated full reviews start from a clean regenerable workspace and do not accumulate old media/metadata.
- `-KeepExistingC11CArtifacts` restores the lighter media-only cleanup behavior when desired.

## Duration policy

The current C11-C review duration remains 18.0 s / 540 frames / 30 FPS. No seed-dependent duration system is introduced in this patch. A later art-direction contract can assign deterministic short/medium/long durations from seed + grammar when the visual review has established which loop families benefit from longer or shorter temporal envelopes.

## Frozen boundaries

No core, simulation, `SimulationResult`, RNG architecture, mechanics, C7 audio contract, or C11-B geometry is modified.
