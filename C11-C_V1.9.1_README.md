# C11-C v1.9.1 — Editorial + Audio + Loop Review Overlay

Copy/extract this ZIP directly over the repository root.

This overlay is presentation-only. It does not modify `core/`, simulation, `SimulationResult`,
engine RNG ownership/version, winning-frame logic, native durations, C7 audio, or C11-B geometry.

## Header
Line 1: large mathematical identity + grammar + seed-resolved motion tag.
Line 2: audience-facing hook with deterministic Matrix-style transition to the family signature.

## Footer
Small generation/data telemetry for prototype and QA. Production can disable it with `-NoFooter`.

## Background
Header/Body/Footer use `C11CTheme.SECTION_BACKGROUND`, currently `#000000`.

## Audio
Deep deterministic ambient bed with low drone and singing-bowl-like resonant carriers.
The audio pulse landmarks use the same integer loop-cycle count as the visual layer.
C7 is untouched.

## Loop
The 10-second export is only accepted as closed when all temporal oscillators complete integer
cycles over the interval. The seed may select 1, 2 or 3 visual cycles.

## Per-video social metadata
Every prototype launcher emits a sibling `_social.txt` containing:
title, description, family, grammar, palette, seed, duration, loop cycles, audio style,
hashtags, and the exact command required to reproduce the individual video.

## Review derivatives
`export_all_review_assets.ps1` generates lightweight review GIFs and keyframe PNGs without
replacing canonical MP4/WAV/GIF outputs.
