# C11-C v2.1.0

This overlay fixes PowerShell parser errors, keeps review/render launchers non-destructive, and introduces a separate protected production product store.

## Validate scripts first
```powershell
.\tools\prototypes\c11c_bulk\validate_c11c_powershell.ps1
```

## Art direction review
```powershell
.\tools\prototypes\c11c_bulk\run_c11c_art_direction_review_v2.1.0.ps1
```

Five random unique seeds × five families = 25 videos. No prototype cleanup is performed. Use `-Seeds ...` to reproduce a batch; use `-ResetReviewAssets` only to reset review images, not prototype videos.

## Cleanup (manual only)
```powershell
.\tools\prototypes\c11c_bulk\clean_c11c_artifacts.ps1
.\tools\prototypes\c11c_bulk\clean_c11c_artifacts.ps1 -Apply
```
The full C11-C reset is separate:
```powershell
.\tools\prototypes\c11c_bulk\reset_c11c_artifacts.ps1
.\tools\prototypes\c11c_bulk\reset_c11c_artifacts.ps1 -Apply
```

## Production
```powershell
.\tools\prototypes\c11c_bulk\run_c11c_production_v2.1.0.ps1 -Family c11c_invisible_forces_v1 -Seed 271828
```

Final products are stored in `artifacts\production\audiovisual\<family>\<product-id>\` and are not touched by review cleanup/reset. Product replacement requires `-Force`.
