# C11-C v2.0.9 — BULK / ART-DIRECTION WORKSPACE HOTFIX

Presentation-only overlay. C11 frozen engineering boundaries remain untouched.

## Fix included

Godot 4.7.1 with warnings treated as errors rejected `C11CColorBoost.gd` because `clamp()` returns a Variant in that context. The code now uses typed `clampf()` values.

## Artifact policy

Render/review launchers **never clean or reset prototype artifacts**.

Use cleanup explicitly:

```powershell
.\tools\prototypes\c11c_bulk\clean_c11c_artifacts.ps1
.\tools\prototypes\c11c_bulk\clean_c11c_artifacts.ps1 -Apply
```

Use the separate full C11-C reset only when you deliberately want an empty regenerable prototype workspace:

```powershell
.\tools\prototypes\c11c_bulk\reset_c11c_artifacts.ps1
.\tools\prototypes\c11c_bulk\reset_c11c_artifacts.ps1 -Apply
```

Neither command is called automatically by a render/review launcher.

## New art-direction launcher

Generate 5 random, unique seeds and apply those 5 variations to all 5 families = 25 videos:

```powershell
.\tools\prototypes\c11c_bulk\run_c11c_art_direction_review_v2.0.9.ps1
```

The seeds used are written to:

```text
artifacts\prototypes\c11c_review_assets\C11-C_ART_DIRECTION_REVIEW_SEEDS.json
```

Repeat a previous batch exactly by supplying its five seeds:

```powershell
.\tools\prototypes\c11c_bulk\run_c11c_art_direction_review_v2.0.9.ps1 -Seeds 1234567,2345678,3456789,4567890,5678901
```

The launcher does not delete existing prototype renders. Only its review-assets output is rebuilt (unless `-KeepExistingReviewAssets` is used).
