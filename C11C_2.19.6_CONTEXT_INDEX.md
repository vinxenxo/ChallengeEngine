## Latest runtime defect

The 2.19.5 worker isolation was real, but fresh worker copies excluded source `.godot`. That meant no generated `global_script_class_cache.cfg`, so Godot could not resolve `PresentationProfile` in `UnifiedSocialFrame.gd`. The prototype still recorded a movie, but the frame content was gray/empty because the presentation script failed to load.

## 2.19.6 repair

`C11CReviewWorkerIsolation.ps1` now bootstraps every worker exactly once with headless Godot editor mode, then checks:

- `.godot/global_script_class_cache.cfg` exists;
- `PresentationProfile` is present.

After bootstrap the worker pool is unchanged: 7 independent roots, lock-free Movie Maker captures, `MAX_OBSERVED_CONCURRENCY > 1`.
