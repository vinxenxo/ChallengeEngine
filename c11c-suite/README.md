# C11-C Suite — 0.1.3

Proof-of-concept operator suite frozen with C11-C 2.18.x.

## Surfaces

- `c11c-test` — logical regression, QA runners and operational contract checks.
- `c11c-catalog` — artifact browsing and metadata inspection.
- `c11c-maintenance` / `c11c-maintenace` — maintenance and archive operations.
- `c11c-config` — low-level declarative configuration inspection/editing.
- `c11c-producer` — audiovisual orchestration.

All GUIs are consumers/orchestrators. They do not implement mechanics, RNG or simulation truth.
