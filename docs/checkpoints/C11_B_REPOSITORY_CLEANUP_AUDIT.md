# C11-B Repository Cleanup Audit

## Purpose

This record explains what was removed, moved or retained during repository organization so future maintainers can distinguish cleanup from semantic evolution.

## Baseline

The input was the owner-supplied `ChallengeEngineV01.2_C11_B_FREEZE_LATEST.zip`, representing the already tested and committed C11-B semantic freeze.

## Kept active

The following remain live and source-controlled:

- engine/runtime code under `core/`;
- canonical challenge and visual definitions;
- profiles and source assets;
- all executable tests and registrations;
- deterministic fixtures/corpora;
- active automation under `tools/`;
- current documentation under `docs/`.

## Moved

| From | To | Reason |
|---|---|---|
| `challenges_c7/` | `tests/fixtures/c7/challenges/` | compatibility test input |
| `challenges_c7_a2_mixed/` | `tests/fixtures/c7_a2_mixed/` | C7 policy test input |

| `qa/c11a1_challenge_qa/` | `artifacts/qa/c11a1_challenge/` | current generated evidence |

| old output/export roots | `artifacts/legacy/` or `artifacts/qa/` | generated/historical evidence |
| root checkpoint documents | `docs/history/` | remove ambiguity from live authority |
| one-off scripts | `docs/history/legacy-tools/` | preserve audit value without active execution |

## Removed from package

Disposable engine/editor caches and reproducible binary outputs were removed from the organized package. They are regenerated by Godot, FFmpeg or the project QA tools.

The cleanup does **not** treat historical manifests, reports or frame digests as disposable merely because their source media was removed.

## Compatibility principle

The test corpus is part of the product. A reorganization is considered safe only when tests resolve the new paths and the full runbook passes without altering deterministic output semantics.

## Post-cleanup authority

Once validated and committed, the organized repository becomes the operational baseline. Historical C11-B freeze evidence remains under `artifacts/releases/c11-b/`; the previous semantic tree hash remains a historical record and is not overwritten.
