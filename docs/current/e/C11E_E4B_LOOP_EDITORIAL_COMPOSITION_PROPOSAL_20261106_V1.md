# E4B Loop Editorial Composition Proposal — V1

<status>`PROPOSED_NOT_APPROVED_NOT_RENDERER_INPUT`</status>

## Problem

C11C `C11CVisualEditorialLayer` has one header label and one footer label. Both already carry family-native grammar/math/metrics/technobabble, seed/duration/FPS/loop count/palette/music/version data, with Matrix animation in the header. Writing D title/subtitle/CTA into those slots would overwrite or occlude protected C11-C output.

## Candidate D-owned outer canvas

- Canvas: 720x1280 (9:16, REVIEW_720).
- Background: `#05070B`.
- Top editorial band: `[0,0,720,192]`.
- Entire C11-C source frame: `[108,192,504,896]`, uniform contain scale `0.7`; no crop, no nonuniform stretch, no temporal resampling. Rect coordinates and dimensions are even for YUV420P.
- Bottom editorial band: `[0,1088,720,192]`.
- Header text boxes use Inter-Bold 15px, max four 19px lines within 92px slots; CTA uses Noto Sans Mono 15px, max three 22px lines. Text source values/hashes remain unchanged; only D-owned line breaks are allowed. No ellipsis or truncation; overflow/font-coverage uncertainty fails closed.
- `language` remains metadata only.
- If title/subtitle/CTA are all empty or `UNKNOWN`, preserve original full-frame pass-through. If any is visible, use one constant layout for the entire source sequence.
- Frame count may only come from the actual C11-C family payload, never from a D9 request; frame index mapping stays identity.

## Preservation and approval conditions

All C11-C native content remains visible and unmodified inside the contained source frame. No C11-C layer/binder/scene/timeline/generator/RNG/music modifications. A review render is required before approval; inspect every field, long Spanish strings, five families, frame zero/transition/end, crop/occlusion and font fallback. Only after explicit visual approval may the geometry become a renderer input. This proposal JSON is explicitly non-executable and cannot grant approval.

## Audio/seed boundary

Visual source is rendered silently with `request.seed`; existing C11-C family music is generated by the current family audio path with `request.music_seed` and unchanged family/profile/grammar/cycle/duration inputs. Never call D3 V5 for Loop. After visual composition, mux audio by stream-copying H.264; mux must not re-encode the video.
