# E4B Loop Full-Family Matrix Review — V1

## Purpose and classification

The full-family matrix simulates the current new Producer's canonical D path over every concrete existing C11-C Loop grammar, while remaining `PLAN_ONLY`. It validates selector identity and D9.8 editorial/seed/music intent across D9.9, D9.10, the existing D-only prepare adapter and E1. It does not produce visual family payloads, pixels, sound or media.

## GUI and CLI

GUI entrypoint: one button inside the current `C11-D · EDITORIAL UNIVERSAL (D9.9)` tab. It writes `matrix_request_template.json`, `matrix_request_template.sha256`, `matrix_report.json` and `matrix_report.sha256` beneath `artifacts/tests/c11e/e4b_loop_family_matrix/E4B_LOOP_GUI_<ID>`.

CLI entrypoint: `RUN_C11E_E4B_LOOP_FAMILY_MATRIX_V1.ps1 -GuiEvidenceRoot <GUI matrix folder>`. The CLI reads the same UTF-8 template and GUI report, runs all 81 cases with CLI origin and compares all editorial identities. It writes its report and runner receipt under `artifacts/tests/c11e/e4b_loop_family_matrix/CLI_<ID>`.

## Explicit non-claims

- E1 fields remain `NOT_CONSUMED_E1`; family adapter remains `NOT_CONNECTED_E1`, gate E4.
- C11-C music generator is not invoked; only profile mapping is read. Music route remains `PRESERVE_EXISTING_C11C_FAMILY_MUSIC_PATH`.
- No Godot, C11-C visual producer, D3 V5, FFmpeg, mux, renderer, dispatch or media.
- The D9.8 `request_plan_compatible=false` model metadata is not changed; actual D9.9 plan-only capability is reported separately.
- Historical D exact-selector materialization remains limited to Geometric Waves; this matrix does not admit the other families to renderer input.
