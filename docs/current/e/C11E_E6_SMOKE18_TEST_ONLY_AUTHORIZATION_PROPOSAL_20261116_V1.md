# C11-E E6 Smoke18 TEST_ONLY Authorization Proposal — V1

**Disposition:** `PROPOSED_NOT_AUTHORIZED`  
**Basis:** E5 is closed in its declared TEST_ONLY scope. The operator authorized continuation; this proposal does not treat that general instruction as permission to bypass an existing, narrower D4.8 policy.

## Proposed scope

- Exactly 18 audiovisual smoke scenarios: six Challenge, six Visual Loop, six Visual Drill.
- Exact selectors, seeds, family-specific executors, source pins, output roots and acceptance rules must be attached in a frozen E6 manifest before approval.
- Existing E4/E5 artifacts may be reused only where their scope and evidence meet the frozen E6 acceptance predicates; no previously accepted E4 BatchId is rerun.
- Family-specific binders, timelines, mechanics and music remain isolated. No parallel Producer, binder, renderer or sixth suite module.

## Proposed prohibitions

Unless specifically and separately authorized in the signed E6 scope, no production renderer, general D4.8 activation, E1 family adapter connection, production dispatch, production output root, release operation, C11-C modification, D10 promotion or freeze action is permitted.

The E6 scope must explicitly state which family-owned test executors, Godot capture, D-owned composition, D3 music, FFmpeg encoding/mux and FFprobe operations are permitted. An unspecified tool invocation is prohibited.

## Required approval record

Before any media activity, publish a distinct versioned policy/approval record containing:

1. The exact 18 scenario IDs and their pinned source inputs.
2. Whether prior E4/E5 A/V receipts are reused or new outputs are required.
3. Exact allowed executable paths, versions/hashes and argument allowlists.
4. Exact number of launcher/encoder/mux invocations and output paths.
5. The approved TEST_ONLY boundary, one-shot ID reservation, stop-on-first-failure and evidence preservation requirements.
6. Required operator visual/audio acceptance.
7. Explicit statements that E1 remains PREPARE_ONLY, `NOT_CONNECTED_E1` remains unchanged, general D4.8 remains BLOCKED, production dispatch is false and release authority NONE.

## Existing policy conflict

The current D4.8 R1V policy V2 (SHA-256 `0866b53ad4fcdebe74d01f66864b2dfb00eb644ca28dcd59301c8f3208239c07`) expressly forbids Smoke18, audio/D3 generation and FFmpeg mux. It authorizes only the bounded silent R1V capture set. This proposal does not modify that policy. A separate E6 approval and independent governance check are mandatory.

**No E6 media has been authorized or launched by this proposal.**
