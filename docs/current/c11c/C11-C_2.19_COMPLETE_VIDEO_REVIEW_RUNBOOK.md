## Concurrency

The canonical review uses `Workers=7`. Each worker has a private temporary Godot project root and private `.godot` state. Shared worker `override.cfg`, global mutex workarounds and serial fallback are forbidden.

## Normal review

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\tools\qa\c11\run_c11c_complete_video_review.ps1 `
  -Workers 7
```

This is the normal operator path because it preserves an existing COMPLETE corpus and lets the canonical batch create only what is missing.

## Deliberate corpus replacement

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\tools\qa\c11\run_c11c_complete_video_review.ps1 `
  -Workers 7 -Reset
```

Use only when deliberately regenerating the review corpus.

## Identity rules

Review folder keys may use editorial names while Loop manifests retain historical/backend identifiers. Canonical identity mapping is:

- `geometric` → `geometric` → Geometric Waves;
- `fractal` → `fractal` → Fractal Bloom;
- `kaleidoscope` → `sacred_symmetry` → Sacred Symmetry;
- `particle_flow` → `living_particles` → Living Particles;
- `vector_field` → `invisible_forces` → Invisible Forces.

Validators must use this crosswalk and must not rewrite backend identifiers.

## Media path resolution

Canonical Loop manifests may omit `output_mp4` and `mp4`. The reviewer resolves media in this order:

1. `output_mp4` when present and non-empty;
2. `mp4` when present and non-empty;
3. the sibling `.mp4` obtained by removing the `_manifest.json` suffix.

## Evidence

Keep the complete corpus, worker telemetry and validation reports under `artifacts/` on the workstation. The freeze package excludes the heavy `artifacts/` tree but embeds compact acceptance and complete-review reports under `release/evidence/`.
