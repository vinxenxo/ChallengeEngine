# C11-C 2.19 — Complete Video Review Runbook

## Canonical 52-video review

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\tools\qa\c11\run_c11c_complete_video_review.ps1 `
  -Workers 7 `
  -Reset
```

Expected corpus: 27 Visual Loop products + 20 Visual Drill products + 5 Longforms = 52 videos.

## Concurrency

The review uses seven private worker project roots, exposed through the canonical `WorkerRoot` field. Capture jobs overlap. The runner records `maxObservedWorkerConcurrency` and rejects a multi-task run when observed concurrency is less than 2. Do not replace this with a mutex or one-at-a-time loop.

## Lightweight smoke

For fast workstation verification before the complete review:

```powershell
.\c11c-suite\c11c-test\run_c11c_one_video_each_type.bat
```

This produces one Visual Loop, one Visual Drill and one Longform under a unique QA root and validates their final MP4s at 720x1280.

## Visual Drill durations

Tracking: 21s gameplay / 27s total / 810 frames. Saccade, Pursuit and Peripheral Scan: 17s gameplay / 23s total / 690 frames.

The Visual Drill review envelope generator receives an absolute review root and must preserve that root.

`c11c-studio` is not used.
