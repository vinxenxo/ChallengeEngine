## Maintenance and freeze package

Routine cleanup remains conservative. The existing artifact cleaners are retained as known-good operations and are not repurposed as release deletion tools. The final frozen archive is produced only by `tools/maintenance/create_c11c_freeze_zip.ps1`.

The frozen archive excludes generated artifacts, caches, source-control metadata, retired studio trees and transient editor data. It requires a PASS acceptance report by default and refuses to seal while `build_factory.py` is empty or while root capture override residue exists.
