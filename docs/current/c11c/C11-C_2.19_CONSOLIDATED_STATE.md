## C11-A.1 final compatibility hardening

The historical C11-A.1 qualification runner keeps `build_factory.py` as the source of execution truth, but it no longer assumes that the factory manifest must appear at one hard-coded path. After a successful factory process, the runner resolves the manifest in this order: factory-reported `manifest_path`, historical canonical path, then a unique valid `*_manifest.json` discovered inside the current run directory.

Resolution fails closed when no valid manifest exists or when more than one valid manifest for the Challenge is present. No manifest is fabricated or copied from another run. `final_video` and `raw_video` are resolved relative to the resolved manifest directory unless the factory declares an absolute path. The resolved manifest path and provenance are stored in `run_record.json`.
