# C11-C 2.19 — Permanent Rules for Future Work

These rules are carried forward into C11-D and later branches.

1. **Encoding:** one UTF-8 BOM for active PowerShell; no double BOM; executable text should be ASCII-safe where possible.
2. **PowerShell interpolation:** `${variable}` when punctuation follows a variable name and could be parsed as part of the variable token.
3. **StrictMode:** guard optional object properties and process exit variables before reading them.
4. **Media probe objects:** do not discard objects needed later; validate stream presence explicitly.
5. **Root paths:** derive repository root from `$PSScriptRoot` and normalize paths in every wrapper.
6. **Suite registration:** every new human-facing runner receives a Suite entry and a canonical `.bat` wrapper.
7. **Historical separation:** `c11c-studio` is retired history, not an active component.
8. **Worker isolation:** 7 private worker roots, per-worker `.godot`, per-worker `global_script_class_cache.cfg`, `PresentationProfile` registered, no shared `override.cfg`, no mutex, no serial fallback, and runtime evidence of concurrency >1.
9. **Engine protection:** QA/production bugs are fixed in QA/orchestration first; do not change simulation truth, RNG, `SimulationResult`, winning-frame or timing contracts to make a faulty test pass.
10. **Debug oracle:** compare against the immutable 2.16.9 frozen baseline before changing behavior inherited by 2.19.x.
11. **Repair sequence:** `FAIL -> reproduce -> locate exact file -> compare -> minimal change -> targeted test -> regression -> checkpoint`.

12. **Worker bootstrap output:** `New-C11CReviewWorkerPool` must return exactly one pool object; helper/bootstrap functions invoked during pool creation must have their console pipeline output suppressed (for example, `$null = ...`). Otherwise PowerShell converts the assignment into a collection and later `.Root` access fails under `Set-StrictMode`.
13. **Root organization conflicts:** current root metadata that differs from legacy copies must be preserved as a timestamped history snapshot, never overwrite legacy evidence silently.
