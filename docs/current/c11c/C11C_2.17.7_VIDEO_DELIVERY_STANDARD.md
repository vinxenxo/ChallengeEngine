# C11-C 2.17.7 — Video Delivery Standard and Challenge Capture Repair

## Decision

The engine/product default delivery standard is **MASTER_1080: 1080×1920, 9:16**.

The existing **540×960 logical social canvas is not replaced**. It remains the presentation coordinate space. The Challenge simulation canvas remains 1080×1920.

## Delivery profiles

| Profile | Output | Purpose |
|---|---|---|
| `MASTER_1080` | 1080×1920 | default social master |
| `REVIEW_720` | 720×1280 | existing C11-C review evidence |
| `MIN_540` | 540×960 | minimum social output |
| `META_REELS_FINAL_V1` | 1080×1920 | compatibility alias to `MASTER_1080` |
| `LONGFORM_1080` | 1080×1920 | longform content beyond 90 s |

All profiles preserve 9:16, fixed FPS within 24–60, progressive H.264/MP4, YUV420-compatible output, 3-second closed GOP, AAC-LC stereo 48 kHz at 192 kbps in the current producer.

## Architectural boundary

The profile is a **delivery transform**, not a runtime simulation viewport.

```text
Challenge / Loop / Drill logical composition
540×960
        ↓
source capture / render
        ↓
profile encoder
        ↓
MASTER_1080 / REVIEW_720 / MIN_540
```

For historical Challenges specifically, Godot captures at native **540×960** and FFmpeg scales the finished frames. This preserves simulation timing, coordinates, RNG, `SimulationResult`, `winning_frame`, `close_calls` and mechanic implementations.

C11-C's already-frozen 720×1280 review corpus remains evidence and is not silently rewritten. The new 1080×1920 profile is additive and becomes the default for new production.

## Historical timing rule

Challenge frame counts remain derived from `hook_duration + game_duration + reveal_duration + cta_duration`. Any obsolete `total_duration` field is ignored when it conflicts with the declarative phase sum.

## Launch repair

Windows process launch constructs `--config=<full-path>` and `--audio-output=<full-path>` as single native arguments. The previous 2.17.6 command evidence showed `--config=` followed by the path as a separate argument, which caused `GeneradorMaestro` to reject the configuration.

## Scope

This overlay does not alter simulation/mechanics/RNG, C11-B geometry, C7 ownership, or C9 authoring semantics. It only hardens production orchestration and delivery.
