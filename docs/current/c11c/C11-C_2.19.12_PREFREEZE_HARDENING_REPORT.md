## V35.1 correction after workstation dry-run

The V34 pre-freeze dry-run exposed two maintenance-only problems before any `-Apply` operation: the documentation consolidator contained duplicate UTF-8 BOM bytes, and the root organizer left different-SHA root copies as blocking `CONFLICT` results.

V35.1 fixes both without changing runtime/product behavior. The consolidator now contains exactly one UTF-8 BOM and its `-DryRun` does not create the history directory. The organizer archives a conflicting root source intact under `docs/history/root_conflicts/` with a timestamp, never overwriting the canonical destination.
