## Logical runner retry rule

`tests/run_all.py` may retry only the exact Windows process exit status `0xC06D007F` (signed or unsigned representation), up to three additional attempts with a short delay. This is a process/runtime recovery mechanism, not a contract waiver.

A deterministic suite FAIL marker, a fatal Godot pattern, a timeout, a missing PASS marker after exit code 0, or any other non-zero exit code is still a failure. A successful retry must itself return exit code 0 and emit the required PASS marker. PASS-marker strings are part of the contract and must match the canonical emitted text; punctuation drift is a runner defect, not a reason to weaken the PASS requirement.
