# C11-C 2.19 — Consolidation and Failure-Prevention Rules

## Source of truth

Canonical scripts live in `tools/`, while `c11c-suite` provides GUI/operator access to those scripts. The GUI must never reimplement production or QA logic.

## StrictMode

With Windows PowerShell 5.1 `Set-StrictMode -Version Latest`, declare every property on structured objects before later assignment. Optional JSON properties must be read through `.PSObject.Properties[...]`.

## Challenge routing

Current C11-C Challenge review is `run_c11c_challenge_bulk_qa.ps1`. Historical A1 qualification is `run_c11a1_challenge_bulk_qa.ps1`. They must not be relabelled or silently interchanged.

## Worker isolation

`Workers=7` is genuine concurrency. Workers require private temporary Godot roots and local capture state. No global mutex or serial fallback.

## Artifact policy

Production, QA, regression, release and test evidence are protected. Prototype media and scratch data are regenerable only through explicit safe cleaners. Cleanup never deletes manifests, logs, authoring, social metadata or protected evidence roots.

## Documentation policy

Active docs are unversioned consolidated authorities. Versioned repair notes are historical evidence. The consolidation tool archives only identified superseded material and never overwrites conflicting historical files.

## Freeze package policy

The final source ZIP is created by `create_c11c_freeze_zip.ps1`, only after final acceptance PASS and a non-empty historical `build_factory.py` are present. Generated artifacts are excluded except for the compact acceptance report embedded as release evidence.

## D handoff

D begins with D0 read-only inventory and Challenge recovery. No new mechanic starts before visual parity, asset-family/template, production-request, provenance and seed contracts are stable.


## Generic root cleaners

`clean-videos.ps1` and the legacy root `Make_zip.ps1` are not part of the C11-C freeze workflow. They are not used by the Maintenance Suite freeze action. Use only the explicit C11-C prototype-media cleaner and the fail-closed freeze packager.
