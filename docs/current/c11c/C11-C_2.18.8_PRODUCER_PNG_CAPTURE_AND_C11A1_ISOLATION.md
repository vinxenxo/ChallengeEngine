# C11-C 2.18.8 — Producer PNG Capture + C11-A.1 Factory Isolation

## Scope

Post-freeze additive repair. No C11-B simulation truth, RNG ownership, `SimulationResult`, `winning_frame`, `close_calls`, `WinningFrameDetector`, `RenderedFrameStream`, C7 ownership, C9 semantics, or logical 540x960 geometry are changed.

## 1. Visual Drill Producer capture

The single-Visual-Drill Producer no longer uses AVI as a capture dependency. Godot Movie Maker records a temporary PNG sequence in the Producer scratch directory. The runner waits for the first and final expected frames, and FFmpeg converts the sequence directly into the H.264 source MP4 before delivery-profile processing.

Godot's command-line Movie Maker supports PNG output and documents the sequence as numbered PNG frames. citeturn829233search0turn829233search2

The PNG sequence is strictly intermediate and is deleted with the scratch stage after the production finishes. No AVI is retained or exposed by the Producer GUI.

## 2. Producer GUI

The obsolete global `AVI` retention control has been removed from Producer 0.9.4. The GUI remains orchestration-only.

## 3. C11-A.1 isolation

Historical Challenge qualification requires a native 540x960 source. The C11-A.1 runner now quarantines any pre-existing root `override.cfg` before invoking `build_factory.py`, removes any override leaked by the factory, and restores the original file after the isolated run. This prevents C11-C 720x1280 Movie Maker state from contaminating historical Challenge source capture.

## 4. Regression coverage

- Producer 0.9.4 self-test checks PNG capture and the absence of AVI/`KeepAvi` in the single-Drill runner.
- Producer GUI contract checks the removal of the obsolete AVI control.
- `C11CArtDirectionProductionHygieneContractTest.gd` checks the PNG capture contract.
- `C11A1FactoryIsolationContractTest.gd` checks the quarantine/restore contract.

## 5. Expected result

- Single Visual Drill production: no AVI dependency.
- Historical C11-A.1: native source remains 540x960 regardless of a pre-existing C11-C root `override.cfg`.
