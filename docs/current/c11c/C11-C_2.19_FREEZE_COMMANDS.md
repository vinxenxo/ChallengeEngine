# C11-C 2.19.12 — Final Freeze Procedure

## Preconditions

The workstation must already show:

```text
C11-C 2.19.12 - FINAL CONSOLIDATED ACCEPTANCE PASS
```

The source tree must have passed root organization, documentation consolidation, Suite/QA checks, PowerShell parse/layout/launcher checks and the Maintenance tooling contracts.

## 1. Freeze dry-run

```powershell
.\c11c-suite\c11c-maintenance\run_freeze_package.bat -DryRun
```

The dry-run creates no ZIP or receipt. It validates acceptance, current docs, root cleanliness, `build_factory.py`, exclusion policy and evidence availability.

## 2. Create the frozen archive

```powershell
.\c11c-suite\c11c-maintenance\run_freeze_package.bat
```

This is the only supported C11-C freeze package path.

## 3. Verify the receipt

Record together:

- frozen archive name;
- archive SHA-256;
- source-tree SHA-256;
- `build_factory.py` SHA-256;
- package manifest;
- compact acceptance/review evidence.

## 4. D entry

After verification, treat the frozen archive as immutable. Do not continue C11-C development in that source tree. Start D0 from a copy of the sealed archive and verify its hashes before modification.
