## 2.19.5 final repair scope

The final repair candidate contains two workstation-validation corrections that do not reopen frozen engine truth:

1. **Parallel review worker isolation:** each Art Direction worker owns a separate temporary Godot project root. `override.cfg`, `.godot` and Movie Maker state are therefore worker-local. No project-global mutex is permitted.

3. **Movie capture helper:** `C11CMovieCapture.ps1` is deliberately non-serializing. It only creates/restores the temporary `override.cfg` in the project root it receives.
4. **Focused contract test:** `C11CParallelReviewWorkerIsolationContractTest.gd` enters through `_initialize()` and explicitly rejects mutex-based capture serialization and invalid `$i:` interpolation.
5. **Acceptance gate:** full acceptance now runs the focused parallel contract and validates the Art Direction manifest requires `Workers=7`, `per_worker_temporary_godot_project`, and `max_observed_worker_concurrency > 1`.
6. **Launcher normalization:** canonical Suite BAT launchers set `C11C_PROJECT_ROOT`, execute from the repository root and propagate child exit codes; the misspelled `c11c-maintenace` path remains a compatibility delegate only.

## Parallel Art Direction architecture

Canonical runner:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\tools\prototypes\c11c_bulk\run_c11c_art_direction_batch_v4.ps1 `
  -Workers 7 `
  -Loops `
  -Reset
```

The worker pool is genuine concurrency. `New-C11CReviewWorkerPool` creates one temporary project root per worker before jobs begin. The worker copy excludes generated `artifacts/`, source `.godot/`, `.git/`, Python caches, retired `c11c-studio/` and source `override.cfg`. The family launcher executes from the worker root with `--path .`.

The movie helper has **no mutex**. The safety property is filesystem/process isolation, not serialization. `Workers=7` must therefore produce `MAX_OBSERVED_CONCURRENCY > 1`.
