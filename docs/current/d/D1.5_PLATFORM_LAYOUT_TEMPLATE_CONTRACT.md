# D1.5 — Platform Layout Template Contract

Status: C11-D D1.5 CONTRACT

This contract defines declarative platform presentation topology.
It does not calculate mechanics, timing truth or RNG.

## 1. Canonical logical frame

The recovered C11-B/C presentation contract establishes a logical social canvas of 540x960.

Logical width: 540
Logical height: 960

The physical Challenge delivery boundary is separate:

Delivery width: 720
Delivery height: 1280
Delivery relationship: post-capture transformation from the logical presentation path.

The logical 540x960 geometry is preserved and is not replaced by the 720x1280 delivery surface.

## 2. Canonical regions

### Header

Rect2(0, 0, 540, 144)

### Body

Rect2(0, 144, 540, 672)

### Footer

Rect2(0, 816, 540, 144)

The three regions completely partition the canonical 540x960 logical frame.

## 3. Presentation topology

UnifiedSocialFrame owns the structural Header/Body/Footer topology.

CoordinateMapper projects logical presentation coordinates into the Body region.

PresentationFramer makes framing policy explicit.

BodyContentRoot remains offset by -144 inside the clipped Body region so existing full-canvas presentation coordinates remain valid.

BodyUIOverlay is reserved for presentation overlays.
