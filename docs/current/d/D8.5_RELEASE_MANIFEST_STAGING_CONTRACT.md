# C11-D D8.5 — Release Manifest + Staging Contract

D8.5 defines deterministic release-manifest construction and the boundary for physical staging.

## Authority

The D8 media scope is the only candidate source. Filesystem discovery, directory names, filenames, historical QA, prior production output and frozen release archives do not create candidates.

The D8.5 manifest produced by the checkpoint is explicitly `NON_AUTHORITY_PREVIEW` while `release_authority=NONE`.

## Determinism

Manifest entries are derived only from the explicit D8 media registry and are sorted by `catalog_key` ascending. No wall-clock timestamp is included in the manifest preview.

## Staging

Physical copy, move, transcode, mux, render, encode and release-product creation are forbidden while `release_authority=NONE`. D8.5 therefore performs no physical staging.

With the current empty registry, the checkpoint closes as `PASS_NO_MEDIA`. A non-empty registry while authority remains `NONE` is `BLOCKED_AUTHORITY_NONE`, not an authorization grant.

## Write boundary

D8.5 evidence may be written only under `artifacts/tests/c11d_d8/d8_5/`.
