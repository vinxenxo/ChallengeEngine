# C11-D D8.1 Media Scope Contract V1

The D8 workspace inventory is forensic. It is not the D8 QA corpus.

Canonical operational scope is `EXPLICIT_REGISTRY_ONLY` and is declared by:
`definitions/c11d/d8/D8_MEDIA_SCOPE_V1.json`

A file is never a D8 QA target merely because it:
- has a media extension;
- is below `artifacts/`;
- is under `production/`, `qa/`, `prototypes/`, `maintenance/` or `tests/`;
- appears in historical C11-A/B/C evidence;
- appears in a frozen archive;
- has a C11-D-looking path/name.

Current registry state: empty (`candidate_count=0`).
Therefore D8.1 must not probe historical media at this stage.

Historical/out-of-scope roots:
- `artifacts/maintenance/**`
- `artifacts/production/**`
- `artifacts/prototypes/**`
- `artifacts/qa/**`
- `artifacts/tests/**`
- `artifacts/regression/**`
- `artifacts/releases/**`

This scope declaration does not authorize production or release execution.
