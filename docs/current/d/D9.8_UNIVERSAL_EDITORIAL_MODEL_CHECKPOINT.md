## 4. Editorial resolution rules

Inheritance is deterministic and ordered:

`global → content_type → family → subtype → variant → production_override`

The resolver rejects unknown layers, unknown scopes, unknown/disabled fields, content-type/scope mismatches, malformed scope maps, non-string text, and text longer than 160 characters. Text is trimmed; `language` is lowercased after trimming; null/empty optional values normalize to `UNKNOWN`. Global values are restricted to `title`, `subtitle`, `call_to_action` and `language`.

Protected data classes remain disjoint from editable editorial values:

- **Derived telemetry:** seeds, FPS, duration, frame count, palette/system IDs, generated statistics and selected difficulty tier.
- **Provenance:** request/plan/personalization identities, source/tool/generator identity and artifact/media hashes.
- **Simulation truth:** mechanics, target, speed, collision/timing semantics, `SimulationResult`, `winning_frame`, `close_calls` and RNG ownership.

Governance assertions preserve `master_seed=NOT_ADOPTED`, gameplay seed=`request.seed`, music seed=`request.music_seed`, forbidden cross-domain seed sharing, no automatic/runtime seed derivation, D4.8 blocked, `runtime_authority=NONE`, renderer/production disabled and `release_authority=NONE`.
