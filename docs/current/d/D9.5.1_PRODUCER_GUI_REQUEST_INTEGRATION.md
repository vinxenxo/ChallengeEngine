# C11-D D9.5.1 — Existing Producer GUI Request Integration

**Target surface/version:** `c11c-suite/c11c-producer` 0.10.0  
**Scope:** request + personalization + canonical plan + GUI/CLI parity only.

## GUI additions

The existing Producer gains the `C11-D · REQUEST + PERSONALIZACIÓN` tab while retaining the original C11-C recipe/queue workflows in the first tab. Controls include mode (REVIEW or PRODUCTION plan), one of the nine Challenges, gameplay seed, independent music seed, five delivery profiles, presentation profile, variation index, audio enabled, and the registered `editorial_text_v1` values: title, subtitle, call-to-action, language, player name and Challenge label.

Defaults are sourced from the existing Challenge definition where appropriate; the operator may edit them. Text length is bounded to 160 characters in the GUI and then validated/normalized by canonical D4.3. The selected Challenge's `mechanic_version` is not misrepresented as `challenge_version`.

## Canonical authorities

- Request normalization: `tools/c11d/d4/production_request_normalizer.py` via D4.6.
- Personalization: `tools/c11d/d4/personalization_resolver.py` via D4.6.
- Plan/hash: `tools/c11d/d4/canonical_production_orchestrator.py` via D4.6.
- CLI comparator: `tools/c11d/d4/production_cli.py` via its shared `process_request` path.
- Delivery alias resolution: the existing central `profiles/delivery/c11c_video_delivery_profiles.json`; the Producer and the new UI helper share one resolver function.
