# C11-D D8.2 Visual QA Contract V1

D8.2 validates visual-QA governance and, when explicitly registered media exist, performs read-only visual inspection on those targets only.

## Canonical scope

D8.2 consumes `definitions/c11d/d8/D8_MEDIA_SCOPE_V1.json` and therefore inherits `EXPLICIT_REGISTRY_ONLY`.
A filesystem-discovered media file is never a D8.2 target by itself.

## Current state

The canonical media registry is empty. Therefore the current D8.2 checkpoint is a governance/empty-scope validation and must not traverse historical media.

## Forbidden

No rendering, no production, no release staging, no modification of C11-C/D7, and no automatic candidate discovery.

When media targets exist in a later checkpoint, visual QA may read them and may create QA-only derived evidence under the D8.2 evidence directory; it must not overwrite or replace source media.

## Inputs

- D8.1 validation receipt.
- D8.1 scope manifest.
- Canonical D8 media scope declaration.

## Empty-scope status

`PASS_NO_MEDIA` means the visual-QA contract and scope are valid but there are no registered media targets.
It does not mean that any release media passed visual QA.

## Evidence

Only `artifacts/tests/c11d_d8/d8_2/` may be written by the D8.2 runner.
