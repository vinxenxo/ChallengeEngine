# C11-D D8.4 — Artifact Eligibility / Provenance-to-Media Contract

## Objective

D8.4 establishes the deterministic boundary between D7 production intent and physical media. It does not render, encode, move, copy, authorize, or publish media.

## Core rule

`D7 catalog intent != physical media != release authorization`.

A physical file becomes a D8.4 candidate only when it is explicitly present in the canonical D8 media scope registry. Files found by filesystem discovery, historical QA, prior production, prototypes, quarantine, tests, or archive locations are not promoted automatically.

## Required linkage

Each registered media candidate must explicitly identify:

- `catalog_key` resolving to exactly one D7.3 catalog item;
- `catalog_item_id` matching that item;
- explicit relative `media_path`;
- explicit SHA-256 for the media bytes;
- explicit provenance/evidence identifiers supporting the relationship.

Filename-only, directory-only, naming-pattern-only, or guess-only linkage is forbidden.

## Historical media

Historical roots remain non-authoritative, including:

- `artifacts/maintenance/**`
- `artifacts/production/**`
- `artifacts/prototypes/**`
- `artifacts/qa/**`
- `artifacts/tests/**`
- `artifacts/regression/**`
- `artifacts/releases/**`

A file in those roots can only become a D8 candidate through an explicit future registry change governed by a later checkpoint. Merely existing there does not confer eligibility.

## Eligibility state

D8.4 can establish only:

`ELIGIBLE_FOR_D8_QA_ONLY`

It cannot establish `AUTHORIZED_FOR_RELEASE`. Release authority remains `NONE` until the later D8.5/D8.6/D8.7 gates.

## Empty-scope state

An empty registry is valid. When `candidate_count=0`, D8.4 may close as `PASS_NO_MEDIA` after validating D7 identity/provenance predecessors and the registry contract.

## Governance

`master_seed=NOT_ADOPTED`; runtime derivation disabled; cross-domain seed sharing forbidden; automatic seed generation disabled; `D4.8=BLOCKED`; runtime authority `NONE`; production execution `false`; renderer execution `false`.

## Mutation boundary

Only `artifacts/tests/c11d_d8/d8_4/` evidence may be written.
