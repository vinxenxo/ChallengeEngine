# C11-D D8.6 — Release Dry-Run + Negative Tests Contract

D8.6 proves release/staging refusal and deterministic manifest behaviour without performing physical release actions.

## Scope

Only `D8_MEDIA_SCOPE_V1` may supply candidates. Filesystem discovery, historical media, frozen release archives and directory names do not create candidates.

## Authority

`release_authority=NONE` remains mandatory. A non-empty explicit registry is therefore a blocked dry-run condition, never an authorization grant.

## Dry-run

The checkpoint performs no copy, move, render, encode, transcode, mux, publish or release-product creation.

The current empty scope closes as `PASS_NO_MEDIA`.

## Determinism

The manifest serialization is derived only from the explicit registry, sorted by `catalog_key`, with no wall-clock timestamp.

## Negatives

The checkpoint validates that synthetic/historical/discovered media cannot enter the candidate set and that an explicit synthetic candidate is refused while authority is `NONE`.

## Write boundary

D8.6 evidence may be written only under `artifacts/tests/c11d_d8/d8_6/`.
