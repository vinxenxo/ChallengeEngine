# C11-D D9.0 — Real Media Pilot Contract

## Status

D9.0 OPEN / PREFLIGHT ONLY.

## Purpose

Establish the controlled boundary for the first real C11-D media artifact after D8.7.

## Rules

- D8.7 remains the accepted D8 control-plane authority.
- `release_authority=NONE` remains in force until an explicit pilot authorization step is performed.
- `production_execution=false` and `renderer_execution=false` remain unchanged during preflight.
- No C11-C simulation/mechanics/RNG/presentation contract is modified.
- No automatic or runtime seed generation is introduced.
- Gameplay `seed` and `music_seed` remain independent.
- Only one explicitly registered pilot case may be rendered in the first real-media qualification.
- Historical media under `artifacts/` is never promoted by discovery.
- The D8 media scope remains explicit-registry-only.

## Pilot sequence

`D9.0 preflight -> explicit pilot authorization -> D9.1 single-case render -> D8.1-D8.6 media QA -> D9.2 producer parity`

## Required first pilot evidence

The first media artifact must have:

- canonical D7 challenge identity;
- explicit delivery profile and mode;
- explicit gameplay seed;
- explicit music seed;
- deterministic production request/plan identity;
- physical output path under a dedicated D9 pilot area;
- provenance back to the D7 identity;
- no dependency on historical media.

## Forbidden in D9.0 preflight

- rendering or encoding media;
- modifying `artifacts/production`, `artifacts/qa`, `artifacts/prototypes`, `artifacts/maintenance`;
- modifying `release/` or `artifacts/releases/`;
- changing D7 authorities;
- enabling D4.8;
- changing production or renderer activation flags.
