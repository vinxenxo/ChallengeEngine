# C11-D D8.1 — ENTRY BRIEF

## Objective

Verify the technical readability and structural integrity of every existing probe-eligible media file without modifying media and without granting release eligibility.

## Exact sequence

`D8.0 inventory → inventory drift check → ffprobe environment → read-only probe → structural integrity result → mutation guard → receipt`

## Non-goals

D8.1 does not perform visual QA, audio/loudness QA, provenance-to-media matching, release staging, release manifest creation, encoding, transcoding, muxing, or publication.

## Failure philosophy

Never silently skip a media file that falls within the generic probe scope. Known raw/ambiguous formats are explicitly classified as not generically probeable rather than falsely certified.

Any current-media drift from D8.0 must be surfaced as a blocking condition.


## V1.1 scope correction
D8.1 compares inventory drift against the same global workspace-media universe recorded by D8.0. Probe execution remains limited to media located under `artifacts/` and `release/`. Adding D8.1 code/documentation/evidence must not cause a false-positive drift.
