# D9.6 — Catalog 0.2.0 integration contract

## Status at overlay creation

Implementation and isolated tests are prepared. Windows GUI smoke and actual-local-artifact verification remain pending.

## Existing GUI surface

The existing `c11c-catalog` is upgraded from 0.1.x to **0.2.0**. The generic artifact browser remains available. A second tab, `C11-D PRODUCTS / PROVENANCE`, is added to the same app; there is no new suite and no `c11c-studio` dependency.

## Explicit record authorities

1. **D7.3 canonical intent records**: only project-local `d7_3_canonical_catalog.json` with D7.3 PASS/CLOSED, D7.3 validation PASS and D7.4 identity receipt PASS/CLOSED. Rows remain `PLAN_ONLY`; a catalog intent is not physical media.
2. **D9.4 media rows**: only the five exact rows in `d9_4_acceptance_manifest.json`, with a PASS/CLOSED D9.4 receipt. Each path must remain inside the project root and match the recorded SHA-256 and byte size. These rows are `VALIDATED_PILOT`, not release products.
3. **Producer GUI plan records**: only `producer_gui_receipt.json` files using `C11-D-D9.5.1-PRODUCER-GUI-RECEIPT-V1`, with matching request identity, plan companion files, hash/parity identity and all execution/authority guards in a blocked/false state. These are `PLAN_ONLY` rows.

The module does not do arbitrary filesystem-to-product inference. Invalid paths, manifest tampering, incomplete plan folders, mismatching hashes, invalid parity and policy/authority violations are surfaced as issues and those rows are not admitted as trusted products.

## UI behavior

- Search/filter canonical intents, plan-only requests and pilot media.
- Inspect record details, explicit source receipts and provenance links.
- Open the evidence/media folder through the existing explorer helper.
- Copy the canonical D4.5 CLI command to regenerate a plan from a saved Producer request. Copying never executes the command.
- Generic artifact browsing and ffprobe/image preview are preserved.

## D8 scope guard

Before showing D9.4 pilot files, Catalog verifies the D8.7 PASS_NO_MEDIA/CLOSED receipt and that the canonical `EXPLICIT_REGISTRY_ONLY` media scope remains empty with `release_authority=NONE`. If that gate changes or is missing, pilot media projection is blocked.

## Safety boundaries

`renderer_execution=false`; `production_execution=false`; `release_authority=NONE`; `media_rendered_by_catalog=false`. D9.1-D9.3 remain validation pilots and are labelled `NOT_REGISTERED_FOR_D8_RELEASE`. D4.8 remains BLOCKED. No changes to `core/`, Challenges, C11-C simulation/truth/RNG, C7/C9 contracts or logical geometry.
