# C11-D D2.0 — Asset Family Audit / Contract V1.0

## Purpose

Establish the evidence boundary for reusable C6 Challenge assets before any promotion into a declarative asset-family registry.

## Canonical rules

1. Existing asset_family and asset_family_version remain evidence-backed metadata.
2. Asset roles are authoritative only when supported by explicit source evidence or D0 evidence.
3. UNKNOWN is valid and must remain explicit when evidence is insufficient.
4. Matching SHA-256 does not by itself justify collapsing distinct assets.
5. Historical assets remain provenance/reference until explicitly promoted.
6. D2.0 does not modify rendering, simulation, mechanics, RNG, frozen contracts, or C11-C production paths.
7. The D2 family registry must be derived from evidence, not filename semantics alone.
