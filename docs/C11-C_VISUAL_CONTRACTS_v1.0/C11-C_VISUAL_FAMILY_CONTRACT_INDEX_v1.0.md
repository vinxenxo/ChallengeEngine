## Shared prototype rule

Each family proceeds:

`contract → isolated prototype → 1 canonical physical render → MP4 + GIF → visual review → acceptance/revision`

No family is considered product-ready merely because code executes successfully.

## Reference-image rule

Future reference images refine the art direction at the **presentation layer**. They may alter visual parameters, palettes, proportions, motifs or motion language, but they must not cause changes to frozen simulation or C11-B architecture.

## Artifact rule

Each accepted prototype should produce at minimum:

- `*.mp4`
- `*.gif`
- `*_manifest.json`

The GIF is the primary human review artifact.
