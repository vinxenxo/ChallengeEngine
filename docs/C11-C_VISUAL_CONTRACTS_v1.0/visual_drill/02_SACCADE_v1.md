# C11-C.7 — VISUAL DRILL / SACCADE v1
## Family Visual Contract

**Family:** `VisualDrill / saccade`  
**Identity:** discrete target relocation / precision / spatial jump

### 1. Purpose
Create clean, mathematically composed spatial targets for discrete gaze shifts while preserving unmistakable before/after target states.

### 2. Mathematical visual language
Positions derive from deterministic spatial distributions, symmetry groups, polar coordinates and bounded geometric layouts. Target transitions may use rings, pulses or brief geometric emphasis, but the endpoint remains exact.

### 3. Composition
Targets remain well inside Body and avoid visually confusing alignments. Centre, horizontal, vertical and diagonal structures may be used intentionally, but accidental symmetry that creates multiple plausible targets should be avoided.

### 4. Motion
The target relocation itself is discrete. Any transition animation is purely presentational and must not obscure the target onset or endpoint.

### 5. Palette
Target contrast is highest at onset and endpoint. Background geometry is thin and subdued. Accent colour may mark the active target only.

### 6. Acceptance
The active location is immediately identifiable, endpoint remains stable, no competing target is equally salient, and the mathematical composition looks deliberate rather than decorative.

### 7. Banned
No cluttered trails that imply a continuous target path, no repeated decoy highlights, no flashing unrelated elements.
