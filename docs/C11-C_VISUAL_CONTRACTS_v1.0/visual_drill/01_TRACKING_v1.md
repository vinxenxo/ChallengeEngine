# C11-C.6 — VISUAL DRILL / TRACKING v1
## Family Visual Contract

**Family:** `VisualDrill / tracking`  
**Identity:** smooth pursuit / sustained fixation / trajectory clarity

### 1. Purpose
Present a mathematically generated moving stimulus whose trajectory is visually rich but whose target identity remains unambiguous.

### 2. Mathematical visual language
Use analytic trajectories: splines, Lissajous paths, bounded harmonic curves and smooth field-guided routes. The path itself can be beautiful; the target must remain the perceptual hero.

### 3. Composition
The target path remains within the Body and avoids unnecessary edge clipping. Background structure is subordinate. A quiet contrast field surrounds the target whenever possible.

### 4. Motion
Continuous velocity; no abrupt direction changes unless the drill configuration explicitly encodes them. Preferred velocity profile is smooth and periodic.

### 5. Palette
High target/background contrast. Decorative mathematics uses lower luminance and opacity than the target. Accent colour may follow instantaneous target speed but must never reduce discriminability.

### 6. Acceptance
The target can be followed continuously without ambiguity; trajectory is mathematically smooth; repeated renders are deterministic; the visual remains premium without compromising the drill stimulus.

### 7. Banned
No decorative motion that competes with the target, no uncontrolled particle field behind the stimulus, no flicker, no ambiguous duplicate targets.
