# C11-C.8 — VISUAL DRILL / PURSUIT v1
## Family Visual Contract

**Family:** `VisualDrill / pursuit`  
**Identity:** continuous following / smooth motion / controlled complexity

### 1. Purpose
Provide a single dominant moving stimulus embedded in a mathematically elegant environment that supports sustained visual pursuit.

### 2. Mathematical visual language
Use smooth analytic curves, bounded-frequency Lissajous variants, spline-like routes and low-frequency field distortions.

### 3. Composition
The target occupies a stable perceptual scale. The environment can echo the route using faint geometry, but echo elements must remain subordinate and non-target-like.

### 4. Motion
Continuous trajectory with smooth velocity and acceleration. Preferred loop motion is periodic and free of seam jumps.

### 5. Palette
Use a strong target accent against restrained mathematical background tones. Background brightness should not rise to target intensity.

### 6. Acceptance
One dominant moving object; smooth trajectory; no false targets; clear contrast; deterministic repeated rendering; visually coherent mathematical environment.

### 7. Banned
No multiple equally salient moving objects, no jitter, no arbitrary acceleration spikes and no environmental animation that makes the target hard to follow.
