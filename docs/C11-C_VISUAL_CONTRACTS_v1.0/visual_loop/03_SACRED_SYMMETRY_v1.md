# C11-C.3 — SACRED SYMMETRY v1
## Family Visual Contract

**Family:** `VisualLoop / kaleidoscope`  
**Status:** APPROVED FAMILY SPEC / READY FOR ISOLATED PROTOTYPE  
**Identity:** symmetry / architecture / hypnosis / order

### 1. Artistic premise
A mathematically exact radial composition inspired by mandalas, rosettes and architectural geometry, but rendered as contemporary generative design rather than a decorative kaleidoscope.

### 2. Mathematical grammar
- radial symmetry groups;
- reflection and rotation operators;
- regular polygons and star polygons;
- rosettes;
- deterministic tessellation;
- layered opacity intersections.

Canonical symmetry order is selected from `{4,6,8,10,12}`.

### 3. Composition
- Fixed optical centre `(270,336)` Body-relative.
- Symmetry axis must remain visually stable.
- Hero radius `160..216 px`.
- Structure expands/contracts toward the Body boundaries without clipping.
- Composition should preserve radial negative space between major rings.

### 4. Motion
Motion derives from aperture-like expansion/contraction, phase offsets between rings and controlled rotational relationships. Rotation alone is never sufficient. The full 10 s loop must close mathematically.

### 5. Light and palette
Default visual language: warm ivory `#EAE0D5`, bronze `#C6AC8F`, white highlight over an almost-black blue background. Intersections create layered luminance. Avoid metallic photo-realism; the material impression comes from line density and light.

### 6. Depth
Three semantic layers: base geometry, transformed mid-layer and fine accent nodes. Depth is conveyed by opacity, line density and controlled scale differences.

### 7. Banned
No ornamental ethnic imitation, photographic ornament, uncontrolled spinning mandala, rainbow cycling or dense edge-to-edge fill.

### 8. Acceptance
PASS requires immediate radial identity, exact symmetry, controlled breathing space, elegant transformation, deterministic closure and no loss of geometric edge clarity.
