# C11-C.2 — FRACTAL BLOOM v1
## Family Visual Contract

**Family:** `VisualLoop / fractal`  
**Status:** APPROVED FAMILY SPEC / READY FOR ISOLATED PROTOTYPE  
**Identity:** infinite / organic / microscopic / luminous

### 1. Artistic premise
A recursively generated structure that feels alive: branching, blooming, folding and zooming into apparently infinite mathematical detail. It must not resemble a static Mandelbrot wallpaper.

### 2. Mathematical grammar
Allowed foundations:
- Mandelbrot/Julia-style escape fields;
- recursive branching / L-system-inspired geometry;
- iterated radial deformation;
- distance-field-inspired contours;
- deterministic phase modulation.

Primary composition should be generated around a stable central attractor. Complexity grows from mathematical iteration, not textures.

### 3. Composition
- Body only; no Header/Footer intrusion.
- Hero centre: `(270,336)` Body-relative.
- Hero radius target: `150..216 px`.
- Dense core occupies approximately `15..30%` of hero diameter.
- Outer filaments must retain visible breathing space.
- At least one visually quiet region must remain identifiable in the Body.

### 4. Motion
Canonical 10 s loop. Preferred motion: logarithmic-feeling zoom, recursive growth, phase breathing and slow deformation. Motion must feel continuous and organic; no constant-speed ornamental rotation.

### 5. Light and palette
Primary family palette: deep cyan `#00B4D8`, sea green `#00F5D4`, blue-white highlight. Background remains deep non-black. Brightness concentrates naturally where recursive structures overlap. Bloom is subtle and preserves filament definition.

Palette is parameterized by seed; hue variation remains within the family’s cool bioluminescent envelope.

### 6. Depth
Use iteration level, scale, opacity and line-width modulation to imply depth. Higher-frequency fine detail should usually be less intense than the principal structures.

### 7. Banned
No photographic nebulae, texture maps, AI-generated clouds, uncontrolled chromatic cycling, noisy fractal static or arbitrary zoom jumps.

### 8. Acceptance
PASS requires: recognizable fractal identity; organic growth; stable centre; contained geometry; no visible loop seam; deterministic re-render; visually premium density rather than uniform clutter.
