# C11-E Loop Family Music Historical Route Reconciliation — V1

Historical C11-E roadmaps explicitly preserve C11-C family music for Visual Loop and Visual Drill; D3 Music V5 is the Challenge route. Existing C11-C logs show `FAMILY_MUSIC_V4` generation per family using `music_seed`, profile and semantic grammar. The current registry binds Visual Loop families to `ORGANIC_BLOOM`, `CIRCUIT_PULSE`, `FLOWING_VECTOR`, `ORGANIC_BLOOM`, and `ORBITAL_RITUAL` respectively.

R1P now provides the independent `gameplay_seed` and `music_seed`, exact loop cycles, duration and grammar. The old C11-C launcher `-NoSound` branch is retained for the immutable source visual capture because its internal music branch consumes its own seed parameter; the integrated R1V orchestration calls the existing family helper with the R1P music_seed, then muxes AAC into a separate AV copy. It is one audiovisual slot, not a separate audio-only testing phase, and does not introduce a new generator or binder.

Challenge remains on D3 V5 where separately authorized; it is not changed by this Loop amendment.
