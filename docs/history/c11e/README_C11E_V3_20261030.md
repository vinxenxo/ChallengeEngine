## Regla de autoridad

En el workstream E sobre el checkout `main`, `AGENTS.md` y `.continue/rules/CONTINUE.md` enrutan al conjunto de documentos anterior. Las decisiones históricas de D siguen siendo evidencia válida de lo que D aprobó o bloqueó, pero no son autoridad operativa para impedir las pruebas del programa E. E tiene gates propios. Ningún gate E puede modificar retroactivamente un recibo D ni conferir autorización de release por el mero hecho de generar un MP4 de prueba.

C11-C 2.19.12 permanece como baseline de producción protegido. Las referencias C se reutilizan cuando el código y los contratos vigentes las confirmen; no se editan sus paquetes congelados ni se copia un ZIP de snapshot sobre el checkout.
