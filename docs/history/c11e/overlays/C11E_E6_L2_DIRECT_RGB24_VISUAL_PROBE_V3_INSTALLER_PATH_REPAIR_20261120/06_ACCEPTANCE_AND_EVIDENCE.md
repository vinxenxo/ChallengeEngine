# V3 acceptance and handoff

A successful V3 install requires `POWERSHELL_5_1_AST_PARSE=PASS/INSTALLER`, 29/29 ZIP members, 24/24 destination postimages, immutable C11-C/D4.8 pins, 20/20 source pins, `RECEIPT_DIRECTORY=PASS/CREATED_BEFORE_PAYLOAD_WRITES`, short sibling receipt temps and `INSTALL_STATUS=PASS_ADD_ONLY`.

Then run the 72 focused tests once and the V3 runner once. The runner remains a one-frame test-only visual probe. It must prove TypographyLabel global class registration before the second Godot process, capture from a fixed 720x1280 SubViewport and produce the source and composited previews.

A successful technical receipt is not operator visual acceptance. Inspect the actual images and the three V2.7 synthetic previews; explicitly decide resampler quality. L3/L4 and Smoke18 remain later separate gates.
