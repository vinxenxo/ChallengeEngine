# C11-C 2.17 — Challenge Production Change History

Historical record. Current authority is under `docs/current/`.

## 2.17.3–2.17.4
Initial additive Challenge producer attempted direct physical 720×1280 Movie Maker rendering. Smoke failed. Direct Godot testing showed Movie Maker itself was functional while PowerShell native user-argument delivery was unreliable.

## 2.17.5
Moved launch to `System.Diagnostics.ProcessStartInfo`, added redirected diagnostics and integrated the existing C11-C Movie Maker override machinery.

## 2.17.6
Restored historical Challenge source capture to 540×960; moved delivery scaling to FFmpeg/Lanczos. Added stale `override.cfg` quarantine, canonical phase-sum timing and explicit C7 raw-PCM declaration.

## 2.17.7
Added central delivery profiles and declared `MASTER_1080` (1080×1920) the default product delivery while retaining `REVIEW_720` as C11-C review evidence.

The user's smoke exposed a malformed native argument shape in the command evidence: `--config=` was separated from its path. That was repaired in the 2.17.7 launch construction.

## 2.17.8
The user's next smoke reached the source-capture validation, proving that Godot accepted the Challenge configuration and produced a source AVI. The wrapper then failed only because a Unicode log-string assertion did not match the mojibake created by Windows process-output decoding.

2.17.8 fixes that failure by:

1. forcing UTF-8 stdout/stderr decoding;
2. removing log text as authoritative source-resolution evidence;
3. making FFprobe of the real source AVI the authoritative source check;
4. retaining log matching only as warning telemetry;
5. keeping all delivery profiles post-capture;
6. updating the current documentation and QA revision.

## Architectural record

The production system distinguishes simulation coordinates, logical presentation coordinates, source capture resolution and final delivery resolution. This is the required basis for robust multi-quality production across Challenges, Visual Loops and Visual Drills without changing gameplay truth.
