## Root cause

`c11c-suite/c11c-producer/main.py` writes seven parity checks for the current D9.10 GUI/CLI/adapter receipt. The D9.13 lifecycle builder in `tools/c11d/d9/cross_suite_lifecycle.py` required an exact six-key set. The valid current GUI receipt therefore failed closed before any lifecycle receipt was emitted. Qt font warnings were incidental and not causal.
