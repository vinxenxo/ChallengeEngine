# C11-C 2.19.x — Final Changelog

## 2.19.0 — Producer AVI capture route repair

The single-Visual-Drill Producer returned from the experimental non-AVI route to a **temporary AVI** route because AVI capture had already been proven by the canonical review runner. The repair aligned the single Producer invocation with that proven route: project-local `--path .`, `Start-Process`, no explicit `--resolution`, deterministic Movie Maker arguments, stable-file wait, and video-only FFmpeg conversion.

The intermediate AVI is scratch-only and is never part of the published product.

## 2.19.1 — Producer social-hook schema repair

The successful 2.19.0 capture exposed a separate PowerShell schema mismatch: the Producer attempted to read `authoring.json.content.hook`, although the canonical hook source is `profiles/presentation/c11c_visual_hooks.json`. The Producer was changed to consume the canonical hook bank using the established deterministic seed/family-offset selection rule.

No simulation, RNG, timing truth, presentation truth, C7/C9 contract or 540×960 logical geometry changed.

## 2.19.2 — test-contract alignment only

After the first successful 2.19.1 Windows runtime, two contracts were found to still encode the obsolete 2.18.9 OGV route. They were aligned with the working 2.19.1 AVI implementation, including the exact `--path .` argument construction.

**Release identity remains 2.19.1.** The 2.19.2 patch is absorbed as non-runtime test maintenance in the frozen source tree.


## Closure

C11-C closes with **2.19.1 as the functional release identity and frozen D baseline**. The 2.19.2 test alignment is absorbed into the source tree solely so the contract suite matches the already-working implementation; it is not a new runtime/product release.
