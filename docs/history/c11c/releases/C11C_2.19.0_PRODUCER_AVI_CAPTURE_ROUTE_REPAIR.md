# C11-C 2.19.0 — Producer AVI Capture Route Repair

> **Historical status:** superseded for release identity by C11-C 2.19.2. The temporary AVI route described here remains part of the frozen 2.19.1 Producer implementation.

## Problem

The 2.18.9 single-Producer experiment used a non-AVI Movie Maker route. The resulting OGV reached the FFmpeg handoff in an unusable/incomplete state during the Windows smoke test. The OGV path was therefore abandoned.

## Repair

The single Visual Drill Producer returned to the proven temporary AVI route and mirrored the known-good review runner invocation:

```text
Start-Process Godot
--path .
--scene core/presentation/rendering/VisualContentPlayer.tscn
--definition=<resolved envelope>
--write-movie=<temporary .avi>
--fixed-fps 30
--quit-after <total frames>
```

The route deliberately does not pass an explicit `--resolution` CLI argument. The existing Movie Maker override establishes the 720×1280 physical review frame. The runner waits for a stable AVI, then FFmpeg converts video-only input to the silent source MP4. Generated music is muxed separately. AVI is scratch-only.

## Scope

No mechanics, simulation truth, RNG ownership, timing truth, `winning_frame`, `close_calls`, C7/C9 semantics or 540×960 logical geometry were changed.

## Verification

The subsequent 2.19.1 Windows smoke continued from the repaired AVI route and reached `FINAL PRODUCT PASS`.
