## Producer 2.19.1 / 0.9.7

The live Producer is exclusively under `c11c-suite/c11c-producer`. The old root `c11c-producer` tree is not part of the live repository.

Single Visual Drill production uses a **temporary AVI** Movie Maker capture. The invocation mirrors the proven review runner:

```text
Start-Process Godot
  --path .
  --scene core/presentation/rendering/VisualContentPlayer.tscn
  --definition=<resolved envelope>
  --write-movie=<temporary .avi>
  --fixed-fps=30
  --quit-after=<total frames>
```

There is deliberately no explicit `--resolution` CLI argument on this path; the local Movie Maker override establishes 720×1280. After stable AVI creation, FFmpeg takes **video only** into the silent canonical source MP4. `FAMILY_MUSIC_V4` is generated separately and muxed afterwards. The AVI remains scratch-only.

The Producer also uses the canonical `profiles/presentation/c11c_visual_hooks.json` hook bank. It does not read an invented `authoring.json.content.hook` field. Hook selection remains deterministic from seed plus family offset.
