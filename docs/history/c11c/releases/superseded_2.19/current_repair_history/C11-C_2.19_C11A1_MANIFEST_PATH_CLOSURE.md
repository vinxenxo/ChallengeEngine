# C11-C 2.19 - C11-A.1 Manifest Path Closure

## Status

Pre-freeze compatibility repair for C11-A.1. No engine/runtime change.

## Failure observed

The 54-run historical Challenge qualification reached `build_factory.py` with process success but the QA runner rejected the run because it assumed one fixed manifest location:

```text
<runDir>\artifacts\CHALLENGE_001\CHALLENGE_001_manifest.json
```

The historical factory contract already records an authoritative `manifest_path` in its stdout and in reference artifacts. The runner and factory therefore had a path-resolution contract drift.

## Repair

`run_c11a1_challenge_bulk_qa.ps1` now resolves the manifest using: 

1. factory-reported `manifest_path`;
2. historical canonical `<artifactRoot>\<CHALLENGE_ID>\<CHALLENGE_ID>_manifest.json`;
3. unique valid `*_manifest.json` discovered below the current run directory.

A discovered manifest must parse as JSON and contain the expected `challenge_id`. Reported absolute or resolved relative paths are accepted only when they stay inside the current C11-A.1 run directory. Zero candidates or more than one candidate is a hard failure.

`final_video` and `raw_video` are resolved relative to the resolved manifest directory unless they are absolute.

## Evidence policy

No manifest is copied from another run, synthesized from stdout, or silently accepted outside the current run. The manifest-resolution source is recorded in `run_record.json`.

## Scope boundary

This repair affects historical QA orchestration only. It does not modify C11-B simulation truth, RNG ownership/algorithm, `SimulationResult`, `winning_frame`, `close_calls`, `WinningFrameDetector`, `RenderedFrameStream`, C7 audio, C9 semantics or logical 540x960 social geometry.

## Closure expectation

After the focused C11-A.1 contract passes, rerun full acceptance. The freeze remains blocked until all final acceptance stages pass.
