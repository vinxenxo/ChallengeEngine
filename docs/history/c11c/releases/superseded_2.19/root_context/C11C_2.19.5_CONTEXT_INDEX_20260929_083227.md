2.19.5 is a continuity/consolidation revision of the 2.19 branch. It contains the 2.19.4 worker-local concurrency architecture plus one test-harness repair discovered during workstation acceptance: the parallel worker contract test used `_ready()` even though a command-line `SceneTree/MainLoop` script must enter through `_initialize()`. This is a test-runner defect, not evidence that the worker-local production architecture is serial. The production batch remains designed for genuine concurrent workers with independent temporary Godot project roots.
