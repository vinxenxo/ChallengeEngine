# C11-C 2.19.4 — Exclusive Launcher Contract Repair

## Scope

This repair addresses one contract only:

- `c11c-suite/c11c-maintenace/` is the historical compatibility spelling.
- It must delegate to the canonical `c11c-suite/c11c-maintenance/` launcher.
- `c11c-studio` is not part of this path and is not modified.
- No Producer, worker isolation, render pipeline, Godot runtime, simulation, presentation, audio or artifact contract is modified.

## Restored compatibility contract

`c11c-maintenace/run.bat` delegates directly to:

`%~dp0..\c11c-maintenance\run.bat`

with `%*` forwarded unchanged.

`c11c-maintenace/main.py` delegates through `runpy` to:

`c11c-suite/c11c-maintenance/main.py`

## Reason

The launcher verification contract reported:

`Compatibility maintenance launcher does not delegate to canonical c11c-maintenance.`

The canonical maintenance implementation remains authoritative. The misspelled directory remains only as a compatibility alias.

## Validation target

Run:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\tools\qa\c11\verify_c11c_suite_launchers.ps1
```

Expected result:

`C11-C Suite launchers PASS`

No other file is intentionally part of this repair.
