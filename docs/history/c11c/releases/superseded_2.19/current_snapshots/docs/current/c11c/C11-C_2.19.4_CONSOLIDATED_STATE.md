## Parallel Art Direction architecture

`run_c11c_art_direction_batch_v4.ps1 -Workers 7` creates a temporary worker pool. Every worker receives a separate Godot project root copied from the current repository source while excluding:

- `artifacts/`;
- `.godot/`;
- `.git/`;
- `c11c-studio/`;
- cached Python state.

The worker copy also excludes any source `override.cfg`. Each worker therefore creates and restores its own temporary `override.cfg`. The batch no longer uses a project-global mutex.

The batch records a `.c11c_worker_active` marker per worker and reports `MAX_OBSERVED_CONCURRENCY`. For a multi-item loop stage with `Workers > 1`, the batch fails when observed concurrency never exceeds one worker. This prevents a silent regression back to one-at-a-time execution.
