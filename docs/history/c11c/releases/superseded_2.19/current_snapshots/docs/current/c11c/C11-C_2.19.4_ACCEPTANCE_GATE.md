## Art Direction concurrency proof

Run:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\tools\prototypes\c11c_bulk\run_c11c_art_direction_batch_v4.ps1 `
  -Workers 7 `
  -Loops `
  -Reset
```

The expected evidence includes:

```text
[C11-C-WORKER] observed_concurrency=2
...
[C11-C-WORKER] MAX_OBSERVED_CONCURRENCY=<n>
```

`<n>` may be lower than 7 because worker startup and workstation scheduling are external; the contract requires that it exceed 1. The batch itself fails if a multi-item loop run with `Workers > 1` observes only one worker at a time.

The generated loop Movie Maker logs must continue to report `720×1280 @ 30 FPS`, never revert to `540×960` during concurrent review capture, and all requested products must complete.
