## Runtime architecture that is retained

Fresh worker projects intentionally do not inherit source `.godot`. Each worker is bootstrapped once with:

```text
godot.exe --headless --editor --path <worker-root> --audio-driver Dummy --quit
```

The bootstrap must create `.godot/global_script_class_cache.cfg` and register `PresentationProfile`. Capture begins only after all requested worker roots are prepared.

The workstation has already produced genuine `Workers=7` evidence. A serialization workaround is prohibited.
