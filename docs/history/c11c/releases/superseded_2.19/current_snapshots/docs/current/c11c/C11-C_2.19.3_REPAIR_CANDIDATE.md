## 2.19.3-v2 — capture concurrency + suite ownership

The 720×1280 Movie Maker override is stored in the project-global `override.cfg`. The review batch launches up to seven workers, so the old backup/write/restore sequence was a race: one worker could restore/remove the file while another was starting Godot. The repair serializes only this capture transaction with a project-scoped named mutex and releases it immediately after the AVI is stable; FFmpeg/audio work remains parallel.

`c11c-suite` is the canonical active suite surface. The active launchers are statically checked to call their local `main.py` entrypoints and contain no `c11c-studio` dependency. The retired `c11c-studio` tree is not modified.
