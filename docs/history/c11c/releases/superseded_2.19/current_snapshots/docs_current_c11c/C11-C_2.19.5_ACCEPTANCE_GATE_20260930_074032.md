## Diagnostic rule

A 540x960 render appearing in a 720x1280 parallel review is a blocker. It indicates that the shared Movie Maker override was not active for the worker process. Do not solve this by reducing `Workers` to `1`; inspect the shared-override contract instead.

## Freeze rule

No `FROZEN` receipt may be issued while any one of these is unresolved:

- direct suite launcher hangs or lacks a timeout;
- parallel workers are disabled/serialized;
- a suite launcher invokes `the retired legacy operator surface`;
- a review-envelope path resolves to a guessed or stale artifact;
- any C11-B/C7/C9 truth boundary is modified to repair C11-C orchestration.
