# C11-C 2.18.2 — REVIEW_720 Same-Path Production Fix

## Observed failure

The Longform review batch called canonical Visual Loop production with `REVIEW_720`. In that profile the source MP4 is already 720×1280 review delivery, so the wrapper computed identical source and final MP4 paths and executed:

```text
Copy-Item source.mp4 destination.mp4 -Force
```

Windows PowerShell rejects copying a file onto itself. The failure therefore appeared at the orchestration/packaging step after a successful render.

## Repair

`tools/prototypes/c11c_bulk/run_c11c_production.ps1` now resolves both paths and skips `Copy-Item` when they are equal (case-insensitive Windows path comparison). Non-REVIEW delivery behavior is unchanged.

## Scope

This is a production-wrapper safety fix. It does not change renderer logic, simulation, RNG, timing, audio ownership, delivery profile semantics or Longform composition.

## Regression

`tests/C11CProductionReviewCopySafetyTest.gd` verifies the guard remains present.
