# C6-F4.3 — Effective Runtime Promotion

## Estado

Implemented on top of certified `1.2.0-C6-F4.2`.

**Certification status:** OPEN until the Windows/Godot E2E gates pass again.

## Architecture

`GeneradorMaestro.gd` is now a presentation/render Composition Root. It no longer owns:

- mechanic simulation;
- RNG stream infrastructure;
- seed retry orchestration;
- legacy validation orchestration.

Production execution enters through:

`ChallengeRuntimeBridge.run_effective_pipeline()`

The bridge performs the certified F1.1 migration, creates the transient F3-compatible runtime projection, executes F3.1/F3.2/F3.3, applies the existing validation contract, and returns `ChallengeRuntimeContext` plus the validated result.

The previous legacy orchestration has been extracted verbatim at the orchestration level into:

`core/execution/ChallengeLegacyRuntimeOracle.gd`

This class is not a production dependency of the effective runtime. `GeneradorMaestro` invokes it only after the effective runtime has produced its result, and the existing `ChallengeRuntimeBridge.verify_equivalence()` gate compares the oracle result with the effective context.

## Deliberate non-changes

- No mechanic mathematics changed.
- No RNG implementation changed.
- No RNG stream assignments changed.
- No `SimulationResult` contract changed.
- No `WinningFrameDetector` implementation changed.
- No `VideoTimeline` authority changed.
- No dynamic `VideoProfileRegistry` registration introduced.

## Important correction versus the rejected proposal

The rejected proposal referenced two APIs that do not exist in the certified baseline:

- `ChallengeRuntimeBridge.run_full_pipeline()`
- `VideoProfileRegistry.register_profile()`

Neither is used by F4.3.

The legacy oracle is intentionally retained outside `GeneradorMaestro`; deleting the oracle at this stage would remove the independent regression guard required for safe promotion.

## Verification suite

`tests/C6F4EffectiveRuntimeTest.gd` verifies for `CHALLENGE_001..009` that:

1. the effective C6 runtime succeeds;
2. the returned `ChallengeRuntimeContext` is complete;
3. effective validation succeeds;
4. the isolated legacy oracle succeeds;
5. effective/oracle equivalence passes;
6. `GeneradorMaestro.gd` no longer contains the removed legacy orchestration or RNG wiring.
