# C6-F0.3.5 — CTA Regression Repair Record

## Incident

External execution of the packaged C6-F0.3.5 baseline produced:

```text
C6F0_3_5_RUNTIME_BOUNDARY_SUITE PASS
C6F0_3_4_CTA_RENDER_REGRESSION_SUITE FAIL
```

The CTA timeline reachability remained correct, but the presentation render model returned empty CTA strings.

## Root cause

`core/presentation/ChallengePresentationBinder.gd` had been packaged with the pre-F0.3.4 regression:

```gdscript
model["cta_main"] = str(overrides.get("cta_main", ""))
model["cta_sub"] = str(overrides.get("cta_sub", ""))
```

## Repair

The historical defaults are restored exactly:

```gdscript
model["cta_main"] = comp.get("cta_main", "LINK IN BIO")
model["cta_sub"] = comp.get("cta_sub", "¡Juega ahora!")
```

The CTA regression suite is shipped in the repository and registered explicitly by `tests/run_all.py`.

## Certification status

The repair is implemented and statically checked. The post-repair CTA suite, global corpus, factory batch and affected physical artifact remain the next execution gate.
