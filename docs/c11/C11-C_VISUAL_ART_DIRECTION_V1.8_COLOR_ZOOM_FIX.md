# C11-C v1.8 — ART DIRECTION: COLOR + ZOOM + INVISIBLE FORCES FIX

Status: review candidate.

## Color direction
Color is now a first-class seed dimension across all five Visual Loop families. Palette banks are deliberately farther apart while remaining inside each family's contract. Sacred Symmetry also uses role-based multi-color structure under exact radial symmetry; Living Particles uses materially different oceanic bioluminescence colorways.

## Fractal Bloom
Zoom is no longer the dominant recurring motion. Each grammar receives a restrained zoom span; recursive/domain detail carries more of the sense of scale. Nested Worlds retains the largest span, while Filigree/Radial are intentionally restrained.

## Invisible Forces
The quadrupole implementation removes the problematic atan/derivative combination implicated by the observed Windows compatibility-driver crash `0xC06D007F` on seed 4. It uses a polynomial quadrupole harmonic and a derivative-free gradient approximation for that mode. Lens and basin scalar fields have been reshaped so the family no longer defaults to a circular radial figure.

No core, simulation, SimulationResult, engine RNG, C11-B geometry or C7 changes.

## Sacred Symmetry chromatic roles
The prototype now has an explicit accent-color role. It is phase/radius modulated with exact sector repetition, so the mechanism can carry multiple warm metal tones without violating radial symmetry.
