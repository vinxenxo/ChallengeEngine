# C11-C 2.15.0 — Art Direction Overlay

## Global editorial direction
- Header expands from 2 to 3 lines and starts one logical line higher.
- Matrix uses one shared resolved font size across every state, with the existing Inter Bold role.
- Footer becomes a 2-line block.
- Section background is dark non-black (`05070B`).
- Palette application receives a controlled chroma increase without changing family hue identity.
- Social sidecars are plain text: no Markdown `**` markers.
- Social sidecars contain `COPY_PASTE_READY` with hook + description + hashtags.

## Longform
- Eight 23 s source chapters per family (184 s raw).
- Seven transitions overlap by 4/7 s, yielding exactly 180 s.
- Video transitions use FFmpeg `xfade=fade`; audio uses `acrossfade`.
- No inter-chapter transition passes through black.
- Final 1 s fade is to black.

## Disk/output hygiene
- AVI is a temporary Movie Maker intermediate by default.
- GIF export is opt-in with `-ExportGif`.
- AVI retention is opt-in with `-KeepAvi`.
- Family renderers accept `-OutputRoot`, enabling isolated extraordinary review corpora.

## Extraordinary review
Use `tools\prototypes\c11c_bulk\run_c11c_art_direction_review_v2.ps1`. Final review assets are grouped into one root with one folder per family. `-Workers 1` is the conservative default; higher values are supported for hardware that can handle concurrent Godot renders. Longforms remain serialized.
