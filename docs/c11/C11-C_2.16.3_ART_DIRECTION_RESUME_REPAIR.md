## 2.16.3 follow-up: concurrent artifact isolation

Invisible Forces has seven grammars but the review seed set contains five seeds. Seeds therefore repeat within that family. Review-only output tags now include the grammar in every artifact stem, preventing concurrent workers from deleting or overwriting each other's authoring snapshots, manifests, social files and MP4s.

Resume builds a pending task queue from the exact current revision and prints a RESUME PLAN before starting workers. Completed current-revision artifacts are skipped; older revision artifacts remain intentionally ineligible after an art-direction change.


### Root cause of the previous failure
Invisible Forces contains seven grammars while the review corpus uses five seeds, so seeds 1 and 2 repeat inside the same family. The old filename was only family+seed; concurrent workers therefore deleted or replaced the same authoring/MP4/manifest/social files. 2.16.3 makes the review filename family+seed+grammar and passes the same tag into the authoring snapshot path.
