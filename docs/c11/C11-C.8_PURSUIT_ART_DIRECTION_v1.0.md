# C11-C.8 — PURSUIT / El Monolito en el Vacío

## Status

Art-direction and engineering handoff only. No Pursuit implementation is introduced by C11-C 2.7.0.

## Visual thesis

Pursuit should feel massive, isolated and foveally important: less like a small moving dot and more like a solitary celestial machine moving through an almost empty field.

## Motion model

The production path is a procedural uniform cubic B-spline. Runtime presentation must receive the authored path state; it must not calculate a replacement mechanic.

### Arc-length parameterization

A sampled cumulative arc-length table is required for the authored spline. The runtime position is obtained by inverting cumulative distance (binary search over the LUT, followed by local interpolation) so the base traversal speed is constant with respect to curve distance. Direct `t += delta` traversal is not acceptable because it couples speed to local spline curvature.

A later controlled isokinetic modulation may vary speed within a narrow bounded envelope, but it must be an explicit authoring parameter rather than a presentation-side surprise.

## Target geometry

The target is a complex but readable geometric object: either a projected rotating hypercube/tesseract or a restrained Euler-ring gyroscope. Internal rotation is purely cosmetic; the center of mass remains mechanically authoritative.

## Dynamic depth of field

The background may use sparse star particles or dark nebular fields. A presentation-only radial tilt-shift isolates the target using its current authored X/Y position as the focus center. The target remains sharp while background blur increases with radial distance. No blur may obscure task truth.

## Cognitive payload

The principal micro-event is the exact ring alignment (“sizygia”) held for 150–200 ms. At 30 FPS this is 5–6 frames. The authored envelope must contain the exact event count so the study/backend has a deterministic answer sheet.

Example:

```json
{
  "payload": {
    "task": {
      "sizygia_count": 4
    }
  },
  "seed": 5409
}
```

The count is authoritative data, not something presentation discovers after rendering.

## Camouflage zones

Optional low-contrast zones may reduce target/background separation within a safe, bounded range. The target must remain recoverable and must not disappear because of an uncontrolled post-process.

## Seed architecture

Seed-derived authoring may choose spline control points, phase, geometry variant, sizygia schedule/count and bounded speed-modulation parameters. Cosmetic palette/background choices remain isolated from structural mechanic truth.

## Safety / validity constraints

No strobe, no random jitter, no uncontrolled chromatic cycling, no future path disclosure, no target destruction through bloom/blur, and no presentation-side generation of mechanic events.
