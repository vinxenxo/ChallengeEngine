# C11-C.8 — PURSUIT MECHANIC BASELINE v1.0

## Authority

Pursuit uses authoring-time deterministic procedural geometry. The authored payload is the single source for the runtime path and cognitive events. Presentation never recalculates the path or creates events.

## Path

- Uniform cubic B-spline over six cyclic control points.
- Control points and the full arc-length LUT are authored in normalized Body coordinates.
- One normalized position sample is authored for every gameplay frame.
- Runtime indexes the authored per-frame samples; it does not advance spline `t` directly.
- A bounded low-frequency speed modulation is authored as a secondary cognitive load while preserving the arc-length parameterization baseline.

## Cognitive payload

Each envelope contains `task.sizygia_count`, `task.sizygia_events[]`, and `task.answer_sheet`. At 30 FPS each event lasts exactly 5–6 frames (150–200 ms). The canonical authoring example uses seed `5409` and yields exactly four sizygias.

## Camouflage

Authoring may emit bounded `camouflage_zones` with a minimum target contrast. The runtime reports the current contrast factor; presentation only applies the visual expression.

## Invariants

- One dominant target.
- Target remains inside Body safe envelope.
- No jitter, no discrete jumps, no presentation-side path synthesis.
- Answer-sheet event count is deterministic from the content seed.


## Study answer artifact
The review generator writes the deterministic `task.answer_sheet` into each run's `authoring.json` under `authored.answer_sheet`, preserving the external-seed request model.
