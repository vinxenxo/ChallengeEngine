# C11-C.9 — Peripheral Scan Mechanic Baseline v1.1

## Purpose

Current authoring/runtime contract for `visual_drill/peripheral_scan`.

## Anchor

The central fixation anchor is rigidly fixed at logical `(270, 480)` / normalized `(0.5, 0.5)`.

## Event authoring

- Three orbital radii are authored in normalized body space.
- Angular positions are produced from a deterministic logistic-map sequence.
- Event kind is authored as `threat` or `distractor`.
- Threats use double flashes; distractors use single flashes.
- Frame start and duration are authored and deterministic.
- High tiers may overlap events deliberately.

## Answer sheet

`authoring.json.answer_sheet` contains:

- `threat_count`
- `distractor_count`
- `threat_frame_starts`
- `distractor_frame_starts`

## Future extensions

Quadrant/bin counting and asynchronous/peripheral rhythm mechanics require new authored response fields and focused regression suites.
