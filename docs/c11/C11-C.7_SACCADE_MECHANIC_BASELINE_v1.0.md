# C11-C.7 — Visual Drill / Saccade — Mechanic Baseline v1.0

## Mechanical identity

Discrete spatial relocation. The target occupies an exact endpoint; there is no spatial interpolation between endpoints.

## Position generator

The baseline uses a deterministic polar distribution with a golden-angle progression. Consecutive endpoints are constrained to a guaranteed jump-distance range of 180–300 logical px and remain inside the logical Body safe zone.

## State machine

- `APPEAR`: 200 ms nominal, represented at 30 FPS by 6 frames.
- `IDLE`: fixation interval controlled by difficulty tier.
- `VANISH`: 50 ms nominal, quantized at 30 FPS to a 2-frame presentation window.

Position remains unchanged during APPEAR/IDLE/VANISH. Only scale and opacity change during the transition phases.

## Presentation

Because this baseline uses an abstract polar/golden-angle jump distribution rather than a meaningful pre-drawn geometric path, it deliberately uses no decorative background. Future geometry-guided Saccade variants may expose a deterministic path layer at low opacity.

## Difficulty

C11-C keeps the existing five canonical tiers and groups them as EASY (1–2), MEDIUM (3), HARD (4–5).
