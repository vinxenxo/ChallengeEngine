# C11-C.9 — PERIPHERAL SCAN MECHANIC BASELINE v1.0

## Authority

Peripheral Scan is authored deterministically from the content seed. Runtime consumes the exact polar event schedule and reports only the current active events and central anchor state.

## Spatial model

- Fixation anchor is rigidly fixed at the logical center `(270,480)`.
- Peripheral events are described by ring index, normalized orbital radius and polar angle.
- Angles come from a deterministic logistic map.

## Event model

The authored task contains exact `frame_start`, `duration_frames`, `kind` and pulse pattern for every event. Threats use a double-flash signature; distractors use a single-flash signature. Difficulty tiers may authorize simultaneous event starts.

The answer sheet contains threat/distractor counts and exact frame starts.

## Invariants

- Central anchor does not move.
- Peripheral events remain inside the declared orbital bands.
- Event duration remains 6–18 frames (200–600 ms at 30 FPS).
- Presentation does not generate additional event timing or solid peripheral target geometry.


## Study answer artifact
The review generator writes threat/distractor counts and exact authored frame starts into each run's `authoring.json` under `authored.answer_sheet`.
