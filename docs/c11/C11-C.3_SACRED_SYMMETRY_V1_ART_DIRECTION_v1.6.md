# C11-C.3 — Sacred Symmetry v1.6 Art Direction Update

## Visual diagnosis from physical multi-seed review

The reviewed keyframes show a strong common identity, but the prior implementation remains too close to a single circular astrolabe: concentric rings, golden rail geometry and similar rotational motion repeat across seeds. The new direction therefore changes the **macro construction** selected by the seed.

## Grammar set

1. `ASTROLABE` — precision rings, axes and orbital markers.
2. `GEAR_TRAIN` — nested exact radial gear profiles with different ratios.
3. `POLYGON_ORRERY` — regular polygons orbiting a central mechanism.
4. `ORIGAMI_MANDALA` — mirrored mathematical folds and stepped openings.
5. `CELESTIAL_CHART` — radial sectors, orbital paths and chart-like nodes.

All modes preserve exact radial symmetry of order `N ∈ {4,6,8,12}`.

## Variation

The seed controls grammar mode, palette family, symmetry order, ring/core scale, node density, tick density, mechanical rate and fold depth.

The palette remains physically warm and metallic but now has controlled variants:
- liquid gold;
- gold/copper;
- amber/laser white;
- bronze/pale gold;
- warm obsidian gold.

The goal is a different **mathematical machine**, not a different decoration around the same dial.

## Banned regressions

- universal circular dial as the default silhouette;
- psychedelic kaleidoscope behavior;
- asymmetry;
- organic/noise-based forms;
- excessive bloom that erases geometric precision.
