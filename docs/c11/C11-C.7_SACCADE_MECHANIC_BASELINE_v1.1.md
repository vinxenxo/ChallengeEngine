# C11-C.7 — SACCADE MECHANIC BASELINE v1.1

## C11-C 2.6.0

Saccade retains discrete relocation: positions are emitted as exact endpoints and never spatially interpolated. Each content seed deterministically authors a polar spatial sequence (angle step, angular offset, radius base and radius variation) before runtime. The authored variants are constrained so adjacent jumps remain within the 180..300 px contract.

The emitted `jump_index` is the sole source for the presentation jump counter. The number shown inside the target is `jump_index + 1`, so the counter changes only when the mechanic enters a new jump cycle.

APPEAR, IDLE and VANISH durations remain mechanic-owned. The visual layer uses scale, opacity and flash only. Cosmetic `saccade_variant` remains presentation-only and cannot alter the authored mechanic sequence.
