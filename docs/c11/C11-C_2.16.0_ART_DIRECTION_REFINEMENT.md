# C11-C 2.16.0 — Art Direction Refinement

## Baseline
C11-C 2.15.1 remains frozen as the stable manufacturing milestone. This overlay starts the post-freeze visual refinement line.

- Header content is bottom-anchored against the Body boundary.
- Footer supports up to 3 lines, 16 logical px, top-anchored against the Body boundary.
