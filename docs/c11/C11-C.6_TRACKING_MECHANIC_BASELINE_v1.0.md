# C11-C.6 — Visual Drill / Tracking — Mechanic Baseline v1.0

## Status
Implemented as **C11-C 2.3.1**. This document freezes the first production-oriented mechanical baseline; art direction remains open for a later review.

## Mechanical identity

**Continuous following + trajectory clarity.**

The drill presents one moving target that can be followed continuously. The target path is deterministic, smooth and bounded inside the logical Body. The canonical task contract remains `type=tracking` with `mode=smooth_pursuit` so the authoring subtype interface stays intact.

## Canonical trajectory

The first implementation uses a bounded **Lissajous 2:3** formulation:

- logical centre: `(270, 480)`;
- x amplitude: `160`;
- y amplitude: `210`;
- x frequency: `2`;
- y frequency: `3`;
- base travel cycles: `0.50`;
- phase offsets: `0.25`, `-0.65`;
- target radius: `12` logical px.

The canonical Body is `0..540 × 144..816` and the target therefore retains substantial clearance from Header/Footer and the lateral edges.

## Motion model

Position is analytic and frame-addressable. The default pacing mode is constant. `accelerating` and `pulsed` modes, when requested by authoring, use smooth sinusoidal phase-rate modulation rather than discontinuous velocity steps.

Velocity is emitted by the mechanic as part of `trajectory_state`. The renderer does not calculate trajectory, velocity, phase or path geometry.

## Target policy

Exactly one target is rendered. The target is the perceptual hero. Canonical tracking contains no distractor objects.

The trajectory trail is **history only**: it contains previous target positions and never reveals future motion.

## Determinism boundary

`tracking_variant` remains part of the established presentation/cosmetic variation channel for compatibility, but it does not modify mechanic truth in this baseline. Two renders with different cosmetic variation values must therefore receive identical target trajectory state for the same mechanical inputs.

## Presentation allowance

The renderer may use a quiet contrast field, a short history trail and high-contrast target geometry. These layers must remain subordinate to target identity and may not introduce alternate moving targets.
