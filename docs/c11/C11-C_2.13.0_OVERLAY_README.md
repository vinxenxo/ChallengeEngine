## Long-form architecture
Long-form is a sequence/composition layer. It reuses the canonical family renderer and audio generator for each 20..30 second chapter, then composes the chapters with FFmpeg. It does not introduce new gameplay truth or duplicate renderers. Five-grammar families use 6 chapters; Invisible Forces uses 7. Each totals exactly 180 seconds. The anthology itself is not a single-loop contract.
