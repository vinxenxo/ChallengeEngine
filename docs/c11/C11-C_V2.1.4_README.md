# C11-C v2.1.4 — Consolidated Final Toolchain

C11-C is the presentation/art-direction layer over frozen C11-B.

## Current delivery

720x1280 / 9:16 / 30 FPS / 540 frames / 18.00 s review baseline.

Godot receives the capture size as one CLI argument: `--resolution 720x1280`.

## Review

```powershell
.\tools\prototypes\c11c_bulk\run_c11c_art_direction_review.ps1 -ResetReviewAssets
```

Generates 5 seeds × 5 families = 25 videos without general artifact cleanup.

## Production

```powershell
.\tools\prototypes\c11c_bulk\run_c11c_production.ps1 -Family <family> -Seed <seed>
```

Products are stored under `artifacts\production\audiovisual` and are protected from review cleanup.

## Frozen boundaries

No changes to C11-B engine semantics, deterministic simulation/RNG ownership, C7, challenge math, or frozen project settings are part of this toolchain consolidation. Variable loop duration remains future work.
