# C11-C 2.13.0 — Current State

This overlay continues the validated C11-C 2.12.0 production/toolchain baseline. The deterministic engine boundaries remain frozen.

## Standard duration policy

Visual Loop chapter duration is policy-driven between 20 and 30 seconds and remains a complete number of authored visual cycles. The standard mapping is 1 cycle = 24s, 2 cycles = 27s, 3 cycles = 30s.

Visual Drills use 3s countdown + gameplay + 3s terminal CTA. Production/review gameplay defaults are Tracking 24s, Saccade 21s, Pursuit 24s and Peripheral Scan 21s, yielding 30/27/30/27 seconds total. Legacy authoring fixtures remain unchanged for regression compatibility.

## Batch seeds

Weekly/monthly production batches use `stratified_spread_random_v1`; seeds are unique and separated by a minimum gap derived from the requested batch size. Monthly validation applies spacing across the complete month, not independently per week.

## Sacred Symmetry

The shared shader has tighter Body containment margins so all major structures remain visible inside the canonical 540x672 logical Body. No frame geometry was changed.

## Three-minute Visual Loop anthologies

A long-form composer reuses the canonical family production launcher. Each chapter is a normal 20..30s Visual Loop generated by the existing renderer and audio generator. Five-grammar families use 6x30s with one encore; Invisible Forces uses 25/25/25/25/25/25/30s. Each family totals exactly 180s. The long-form product is an anthology and is not itself required to loop seamlessly.

## Frozen boundaries
