# C11-C Visual Music Direction v4.0

## Scope

Procedural audio is presentation/delivery metadata. It does not consume gameplay frames, answer sheets, `winning_frame` or `close_calls`.

## Tonal system

All material is derived from an A-minor pentatonic frequency bank. Family profiles retain distinct arrangements, register, texture, stereo behaviour and pacing.

## Deterministic semantic inputs

- Visual Drills: `seed + drill_family`.
- Visual Loops: `seed + visual_family + visual_grammar`.

The Visual Loop grammar is now a real input to motif selection, phase, stereo motion and filter modulation.

## Mobile delivery

- 44.1 kHz stereo source.
- Peak target 0.35 with 0.36 contract ceiling.
- No kick/snare layer.
- Slow ADSR envelopes.
- Slow deterministic low-pass modulation.
- Restrained stereo motion.

- Tracking <-> Invisible Forces: flowing/vectorial.
- Saccade <-> Geometric Waves: precise/pulsed.
- Pursuit <-> Fractal Bloom and Living Particles: organic/blooming.
- Peripheral Scan <-> Sacred Symmetry: orbital/celestial.
- Kaleidoscope / PRISMATIC_MEMORY remains available as the historical/productive pairing path.
