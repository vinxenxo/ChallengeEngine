# C11-C — Visual Variation Model v1.1

## Prototype seed matrix

The four-seed matrix (`314159`, `271828`, `161803`, `112358`) is a plumbing and bounded-variation qualification stage.

Its job is to prove:

- seed transport;
- deterministic parameter selection;
- collision-free artifact naming;
- reproducibility of the same seed;
- bounded family-specific variation.

It is not the production diversity envelope.

## Production seed manifold

Production SHALL widen the family-specific parameter manifold so a different seed can produce an observably different composition while preserving the same visual metaphor.

Examples:

- Geometric Waves: polygon order, frequency ratios, layer spacing, phase offsets, morph depth, palette anchor.
- Fractal Bloom: Julia constant, analytical zoom envelope, domain warp, branch density, layer scale relationships.
- Sacred Symmetry: symmetry order, ring radii, gear ratios, orbital offsets, active-node density.
- Living Particles: density field, attractor placement, swirl strength, turbulence scale, glow envelope.
- Invisible Forces: field topology, streamline density, curvature, pulse cadence, storm center.

The production selector should reject variants that fall outside family BANNED LIST rules or lose the family's defining metaphor.

## Qualification rule before production

The prototype matrix is PASS for renderability and deterministic seed plumbing when each requested seed creates an independent artifact set.

Visual sameness is not a technical failure by itself at this stage. Production diversity is handled by the broader family-specific parameter manifold described above.
