C11-C VISUAL LOOPS — MANUAL OPERATIVO DE COMANDOS
==================================================
Versión de referencia: C11-C v2.1.4
Objetivo: generar, revisar y publicar Visual Loops sin mezclar REVIEW con PRODUCTION.

REGLA PRINCIPAL
---------------
1) REVIEW = experimentación/dirección de arte. Vive en artifacts\prototypes.
2) PRODUCTION = productos finales. Vive en artifacts\production\audiovisual y NO lo toca la limpieza de review.
3) CLEANUP/RESET = operaciones manuales, nunca se ejecutan automáticamente al lanzar renders.
4) No modificar project.godot por C11-C. La captura social usa 720x1280 mediante override temporal.
5) Duración provisional actual del corpus: 18.00 s / 540 frames / 30 FPS. La duración variable queda para una fase futura.
6) Audio: ON por defecto. Para desactivarlo usar -NoSound o -Silent.
7) Cada ejecución produce un único MP4 canónico: <Nombre>_seed_<SEED>.mp4.

Descripción:
Fuerza a Godot a escanear scripts, clases y recursos sin renderizar.
Usarlo:
Como comprobación rápida de carga del proyecto.

Resultado:

25 renders físicos.
GIFs/keyframes de revisión.
Seed manifest para reproducibilidad.

PASO 6 — REVISIÓN CON SEEDS ELEGIDAS

Descripción:
Igual que el anterior pero usando exactamente esas 5 seeds.

==================================================
D. EL COMANDO QUE BUSCAS: 25 PRODUCTOS FINALES (5×5)
==================================================

OBJETIVO:
5 seeds aleatorias × 5 familias = 25 PRODUCTOS FINALES listos para producción.

IMPORTANTE:
No usar run_c11c_art_direction_review.ps1 para esto.
Ese comando es REVIEW.
Para productos finales hay que usar la cadena PRODUCTION.

COMANDO RECOMENDADO — 5 SEEDS ALEATORIAS + 25 PRODUCTOS:

$Seeds = 1..5 | ForEach-Object {
    Get-Random -Minimum 1000000 -Maximum 2147483646
} | Select-Object -Unique

while ($Seeds.Count -lt 5) {
    $Seeds += Get-Random -Minimum 1000000 -Maximum 2147483646
    $Seeds = @($Seeds | Select-Object -Unique)
}

Write-Host "Seeds de producción: $($Seeds -join ', ')"

$Families = @(
    'c11c_geometric_waves_v1',
    'c11c_fractal_bloom_v1',
    'c11c_sacred_symmetry_v1',
    'c11c_living_particles_v1',
    'c11c_invisible_forces_v1'
)

foreach ($Family in $Families) {
    .\tools\prototypes\c11c_bulk\run_c11c_production_bulk.ps1 -Family $Family -Seeds $Seeds
    if (-not $?) { throw "Production failed for $Family" }
}

Qué hace:
- Genera 5 seeds aleatorias únicas.
- Usa exactamente esas mismas 5 seeds en las 5 familias.
- Ejecuta 5 productos por familia.
- Total = 25 productos finales.
- Audio activado por defecto.
- Los productos se publican bajo artifacts\production\audiovisual.
- Cada producto conserva MP4 + logs + manifest + ffprobe + social + authoring + PRODUCT.txt.
- La producción no es objetivo del cleanup de review.

La consola imprimirá las 5 seeds usadas. Conviene conservarlas para poder reproducir la tanda.

==================================================
F. PRODUCCIÓN DE UN SOLO PRODUCTO FINAL
==================================================

Plantilla:
.\tools\prototypes\c11c_bulk\run_c11c_production.ps1 -Family <FAMILIA> -Seed <SEED>

Ejemplo:
.\tools\prototypes\c11c_bulk\run_c11c_production.ps1 -Family c11c_invisible_forces_v1 -Seed 271828

Sin sonido:
.\tools\prototypes\c11c_bulk\run_c11c_production.ps1 -Family c11c_invisible_forces_v1 -Seed 271828 -NoSound

Sin footer:
.\tools\prototypes\c11c_bulk\run_c11c_production.ps1 -Family c11c_invisible_forces_v1 -Seed 271828 -NoFooter

Reemplazo deliberado de un producto existente:
.\tools\prototypes\c11c_bulk\run_c11c_production.ps1 -Family c11c_invisible_forces_v1 -Seed 271828 -Force

ADVERTENCIA:
-Force solo debe usarse cuando deliberadamente quieres sustituir un producto existente.
Sin -Force, producción se detiene si el producto ya existe.

==================================================
I. LIMPIEZA DE ARTIFACTS — MANUAL
==================================================

DRY-RUN (no borra):
.\tools\prototypes\c11c_bulk\clean_c11c_artifacts.ps1

APPLY (borra medios regenerables de prototype):
.\tools\prototypes\c11c_bulk\clean_c11c_artifacts.ps1 -Apply

Qué limpia:
- Medios regenerables de las carpetas c11c_* de artifacts\prototypes.
- MP4, GIF, AVI, WAV, PNG, JPEG, WebP, BMP, MOV, MKV, WebM.

Qué NO toca:
- artifacts\production
- artifacts\legacy
- artifacts\qa
- artifacts\regression
- artifacts\releases
- artifacts\tests
- metadata conservada en prototype

==================================================

DRY-RUN:
.\tools\prototypes\c11c_bulk\reset_c11c_artifacts.ps1

.\tools\prototypes\c11c_bulk\reset_c11c_artifacts.ps1 -Apply

Qué hace:
Elimina los árboles c11c_* de artifacts\prototypes y artifacts\scratch y los recrea.

NO toca:
legacy / qa / regression / releases / production / tests

==================================================
L. VERIFICAR LOS PRODUCTOS FINALES
==================================================

Cada producto se almacena en:
artifacts\production\audiovisual\<familia>\<producto>

Ejemplo:
artifacts\production\audiovisual\c11c_invisible_forces_v1\InvisibleForces_v1_seed_271828\

Archivos importantes:
- <producto>.mp4
- <producto>_social.txt
- <producto>_manifest.json
- <producto>_authoring.json
- <producto>_ffprobe.json
- <producto>_godot.log
- <producto>_music.wav (si audio activo y el WAV se conserva)
- <producto>.gif
- PRODUCT.txt
- production_manifest.json

Catálogo global:
artifacts\production\audiovisual\C11C_PRODUCTION_CATALOG.json

El PRODUCT.txt contiene también el comando de reproducción del producto.
