# C11-C Visual Loop Long-form Architecture v1.0

The three-minute family videos are sequence compositions, not new renderers. Each segment is generated by the existing canonical family production launcher with an explicit technical grammar, seed and duration. The composer concatenates the resulting 720x1280 / 30 FPS products with FFmpeg.

Standard Visual Loop segments remain inside the common 20..30 second policy. Five-grammar families use six 30s chapters: all five grammars once plus a deterministic encore of the first grammar with a different seed. Invisible Forces uses seven chapters: 25/25/25/25/25/25/30 seconds, covering all seven grammars exactly once. Every family therefore totals exactly 180 seconds.

The long-form product is an anthology rather than a single 180-second seamless loop. Each constituent chapter is itself loop-safe; the chapter boundaries are deliberate composition cuts. The audio is likewise chapter-native and deterministic rather than one re-synthesized 180-second master.

This architecture reuses the existing renderers and audio generator and introduces no per-family renderer duplication, no gameplay truth, no new RNG owner, and no changes to C7/C9/C11-B contracts.
