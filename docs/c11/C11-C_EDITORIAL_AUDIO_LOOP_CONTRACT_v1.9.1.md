# C11-C EDITORIAL + AUDIO + LOOP CONTRACT v1.9.1

## Header

Line 1 is the large mathematical identity:
equation + grammar + one seed-resolved mechanical tag.

Line 2 is the large audience-facing hook.
At the deterministic midpoint it transitions with a Matrix-style character scramble
to `VISUAL LOOP / FAMILY`, holds, then scrambles back to the hook before the final frame.

The same seed always produces the same texts and transition characters.

## Footer

Prototype/QA only. Small source/data telemetry.
Production can disable it with `-NoFooter`.

## Background

Header, Body and Footer use one centralized `C11CTheme.SECTION_BACKGROUND`.
Current value is pure black `#000000`.
Future theme passes change this one constant.

## Audio

C11-C audio is presentation-only and must not modify C7.

The audio bed is deep ambient, low-importance, with resonant bowl-like strikes and a
low drone. Its pulse landmarks are derived from the same integer loop-cycle count used
by the visual presentation.

All oscillator counts and strike positions are periodic on the exported 10-second loop.

## Loop

A generated visual is not considered closed merely because the file is 10 seconds long.

Every temporal oscillator must have an integer number of cycles over the exported interval.
Seed-dependent continuous parameters may change amplitude, geometry, phase offsets or
spatial structure but may not create non-integer temporal closure.

## Social sidecar

Every generated MP4 receives a sibling `_social.txt` file containing:
- title
- description
- family / grammar / palette / seed
- duration and loop cycles
- audio style
- editorial behavior
- hashtags
- exact command required to reproduce the individual video.
