# C11-C — Header + Multi-Seed Bulk Rules v1.0

## Header mathematics
The first Header line is the dominant mathematical caption. It uses a fitted font size up to 16 px and down to 11 px, constrained to the 468 px safe width. The complete line is measured against the active Godot theme font before selecting its size.

The second Header line remains metadata. Footer keeps the family title and conceptual hook.

## Multi-seed
Each family launcher accepts `-Seed`. The same seed is passed into the isolated presentation controller and prototype-only audio generator. `314159` remains the artistic reference seed. Default bulk matrix: 4 seeds × 5 families = 20 renders.
