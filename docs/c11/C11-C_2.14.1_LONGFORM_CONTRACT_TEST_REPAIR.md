# C11-C 2.14.1 — Longform Contract Test Repair

## Scope
Repair only the GDScript warning-as-error in `tests/C11CVisualLoopLongformContractTest.gd`.

## Defect
`JSON.parse_string(...)` returns `Variant`. Inferring the local variable type with `:=` caused Godot 4.7.1 to report:

> The variable type is being inferred from a Variant value, so it will be typed as Variant. (Warning treated as error.)

## Repair
The local is now explicitly declared as `Variant`:

```gdscript
var schedule: Variant = JSON.parse_string(FileAccess.get_file_as_string(schedule_path))
```

No simulation, renderer, audio, duration policy, longform schedule, or production launcher logic is changed by this overlay.
