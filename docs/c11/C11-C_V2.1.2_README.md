# C11-C v2.1.2 — Consolidated Presentation/Delivery Toolchain

This overlay consolidates the C11-C presentation layer after iterative v2.0.1–v2.1.2 fixes. It is intentionally rebased on the last known-good v2.0.6 presentation implementation and avoids reopening frozen C11-B engineering.

## What is closed in this revision

- 720×1280 social delivery with temporary viewport + window Movie Maker override.
- 18.00 s / 540 frames / 30 FPS review baseline.
- Vivid palette transform with typed GDScript to avoid Variant inference warnings.
- Restored palette-colored decorative rules and editorial typography.
- Header-only family identity; footer contains telemetry and does not repeat the family label.
- Default safe ambient audio; `-NoSound` / `-Silent` disables it.
- Exactly one final MP4; silent intermediates stay in the OS temp directory.
- UTF-8 BOM-tolerant social metadata generation.
- Review and cleanup separation.
- Protected final-product store and explicit production publishing.
- Canonical 25-video Art Direction 2.0 launcher.

## First commands after overlay

```powershell
.\tools\prototypes\c11c_bulk\validate_c11c_powershell.ps1
.\tools\prototypes\c11c_bulk\validate_c11c_delivery_configuration.ps1
```

Then generate the review corpus:

```powershell
.\tools\prototypes\c11c_bulk\run_c11c_art_direction_review.ps1 -ResetReviewAssets
```

## Canonical production command

```powershell
.\tools\prototypes\c11c_bulk\run_c11c_production.ps1 -Family c11c_invisible_forces_v1 -Seed 271828
```

Final products are written under `artifacts\production\audiovisual\` and are not targets of review/cleanup.

## Important

Historical versioned scripts remain on disk for traceability but are superseded. Use the unversioned canonical tools documented in `tools\prototypes\c11c_bulk\README.md`.

The assistant environment cannot run the user's Windows Godot 4.7.1 build, so the final physical validation step remains the user's local Godot run. The family launchers now fail early if the Godot log does not explicitly report 720×1280 capture.
