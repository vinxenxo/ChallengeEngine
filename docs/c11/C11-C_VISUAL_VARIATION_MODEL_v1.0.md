# C11-C — Visual Variation Model v1.0

## Purpose

Define the distinction between the prototype seed matrix and the future production seed bank.

## Prototype stage

The four-seed matrix (`314159`, `271828`, `161803`, `112358`) verifies:

- seed transport;
- deterministic parameter selection;
- collision-free artifact naming;
- repeatability of the same seed;
- bounded family-specific variation.

The prototype is intentionally conservative so that family art direction remains visually stable while plumbing is validated.

## Production stage

Production generation SHALL use a wider, family-specific parameter manifold. Variation must be visible at the composition level while preserving the family metaphor.

Examples:

- Geometric Waves: polygon order, frequency ratios, layer spacing, phase offsets, morph depth, palette anchor.
- Fractal Bloom: Julia constant, analytical zoom envelope, domain warp, branch density, layer scale relationships.
- Sacred Symmetry: symmetry order, ring radii, gear ratios, orbital offsets, active-node density.
- Living Particles: density field, attractor placement, swirl strength, turbulence scale, glow envelope.
- Invisible Forces: field topology, streamline density, curvature, pulse cadence, storm center.

Every production variant remains deterministic and bounded by its family contract.
