# C11-C.4 — Living Particles v1.6 Art Direction Update

## Visual diagnosis from physical multi-seed review

The reviewed keyframes show a clean bioluminescent particle field, but most seeds still read as the same sparse circular cloud with different count/position/intensity. The new implementation therefore changes the **interaction topology and morphology** selected by the seed.

## Grammar set

1. `SWARM` — collective migrating cloud.
2. `VORTEX` — orbiting matter around an attractor.
3. `COLLISION_CLOUD` — two populations converge, deflect and separate.
4. `ORGANIC_PULSE` — a living central mass expands and contracts.
5. `MAGNETIC_FILAMENT_CLOUD` — density follows a soft dipolar/curl field without drawing hard vector rails.

## Particle morphology

Particles remain soft and translucent. The shader varies round/elliptical micro-morphology, size and spectral state without introducing hard geometric glyphs.

## Variation

The seed controls grammar, palette family, attractor topology/positions, density, particle size, turbulence, interaction strength and temporal rate.

The formal production target remains `10,000–50,000` GPU particles. This v1.6 prototype keeps the lightweight analytic benchmark while establishing the correct visual grammar before the production particle backend is opened.

## Banned regressions

- identical ring-like cloud in every seed;
- hard geometric particles;
- visible vector lines as protagonist;
- Pong-like edge bounces;
- random noise without coherent force behavior.
