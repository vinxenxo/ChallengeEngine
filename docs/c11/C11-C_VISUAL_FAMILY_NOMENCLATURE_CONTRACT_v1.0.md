Exactly five historical Visual Loop families exist. Technical IDs, artistic names and production/runtime IDs are aliases over the same five families.

|---|---|---|---|
| `geometric` | **Geometric Waves** | `geometric` | `c11c_geometric_waves_v1` |
| `fractal` | **Fractal Bloom** | `fractal` | `c11c_fractal_bloom_v1` |
| `kaleidoscope` | **Sacred Symmetry** | `sacred_symmetry` | `c11c_sacred_symmetry_v1` |
| `particle_flow` | **Living Particles** | `living_particles` | `c11c_living_particles_v1` |
| `vector_field` | **Invisible Forces** | `invisible_forces` | `c11c_invisible_forces_v1` |

`profiles/presentation/c11c_visual_family_catalog.json` is the machine-readable source of truth.

This document resolves the historical nomenclature discrepancy without renaming or splitting any family.
