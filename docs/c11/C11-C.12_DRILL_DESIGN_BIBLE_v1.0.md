# C11-C.12 — Visual Drill Design Bible v1.0

## Scope

This is the current cognitive-load roadmap for the four Visual Drill families. It separates already-implemented mechanics from future mechanics so presentation work cannot silently become gameplay truth.

## Tracking

Current: seeded Lissajous smooth pursuit + growing history trail.

Future:
- predictive occlusion tunnel;
- target morph-state counting.

## Saccade

Current: discrete seeded polar relocation + APPEAR/IDLE/VANISH + jump counter.

Future:
- N-back spatial memory;
- flash recognition / orientation task.

## Pursuit

Current: uniform cubic B-spline + arc-length authoring + sizygia + camouflage.

Future:
- depth/scale simulation;
- flanker interference.

## Peripheral Scan

Current: fixed fixation anchor + polar/logistic events + threat/distractor discrimination.

Future:
- quadrant/bin counting;
- asynchronous/polyrhythmic peripheral spawns.

## Authoring rule

Any mechanic that changes what the user must count, discriminate or remember requires deterministic authored response data in `authoring.json` and a focused contract suite.

Renderer-only cosmetic effects must never become the source of answer truth.
