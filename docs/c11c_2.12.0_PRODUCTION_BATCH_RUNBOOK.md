# C11-C 2.12.0 — Production Batch Runbook

## Weekly
`tools/prototypes/c11c_bulk/run_c11c_weekly_production_batch.ps1` publishes the canonical 27-slot weekly schedule through the protected production launcher and then organizes the same finished products under `artifacts/batch/week/XXXX/<day>/.../`. The week id is a random four-digit number unless supplied with `-WeekId`.

## Monthly
`tools/prototypes/c11c_bulk/run_c11c_monthly_production_batch.ps1` repeats the exact 27-slot weekly pattern for the requested number of weeks (default 4) and allocates globally unique seeds across every slot. Four weeks produce 108 products; five weeks produce 135.

## Repetition rule
A video identity is tracked as `family|grammar|seed`. The monthly batch rejects repeated seeds, so the same deterministic combination is never intentionally reused.
