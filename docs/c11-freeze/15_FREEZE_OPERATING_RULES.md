# Freeze Operating Rules

1. Contract before implementation.
2. No unverified PASS claims.
3. Preserve native mechanic and RNG versions.
4. Do not normalize challenge durations merely for QA.
5. Presentation never computes gameplay truth.
6. Generated evidence goes under `artifacts/`.
7. Every freeze gets a reproducible inventory and cryptographic manifest.
8. Art-direction work must stay inside the explicitly opened scope.
9. A contract-breaking request becomes a new checkpoint instead of a hidden exception.
10. The next development window starts from the frozen C11 handover, not from an older ZIP or historical transcript.
