# C11 Freeze Certificate

This document is a human-readable companion to the machine-readable certificate generated by `tools/c11freeze/finalize_c11_freeze.ps1`.

## Required record

- Freeze identifier: C11
- Status: CERTIFIED / FROZEN
- Godot version: 4.7.1-stable
- Repository inventory path
- Retrocompatibility report path
- Stress report path
- Physical smoke manifest path
- QA video matrix manifest path
- Source/documentation SHA-256 manifest path
- Tree SHA-256
- Git HEAD, when available
- Git working-tree status, for traceability

The JSON certificate, not this template, is the machine-readable authority for the exact sealing run.
