# C11-C v2.0.4 — Editorial Palette / Single-MP4 / Social BOM Hotfix

Overlay intended for the C11-C v2.0.3 prototype tooling.

## Changes

- Restores the Header/Footer decorative rules on all five families; rules use the active family palette rather than neutral gray.
- Restores palette-driven colors for Header and Footer text across all five families.
- Removes the duplicated `VISUAL LOOP // FAMILY` footer line; the family identity remains in the Header animation.
- Footer now contains four telemetry lines instead of five.
- Default render produces exactly one final MP4 with audio.
- `-NoSound` and alias `-Silent` produce exactly one final silent MP4.
- The intermediate silent MP4 is now written to the OS temp directory and removed on success/failure; no `_silent.mp4` is left in `artifacts`.
- Legacy `_silent.mp4` files for the same seed are removed automatically at launcher start.
- Social metadata accepts both UTF-8 BOM and UTF-8 no-BOM manifests (`utf-8-sig`).
- Manifest writes are explicitly UTF-8 without BOM for stable cross-tool consumption.
- Multiseed bulk manifest corrected to 18.0 s / 540 frames and defaults to the first 8 production-review seeds.
- Added `run_c11c_style_review_v2.0.4.ps1` to clean regenerable media, reset review assets, render all five families over the seed set, and regenerate review GIFs/keyframes.

## Frozen boundaries

`core`, simulation, `SimulationResult`, RNG architecture, mechanics, C7 audio contracts, and C11-B geometry are not modified.

## Suggested style-review command

```powershell
.\tools\prototypes\c11c_bulk\run_c11c_style_review_v2.0.4.ps1
```

Use `-KeepExistingReviewAssets` only when deliberately retaining the existing review corpus.
