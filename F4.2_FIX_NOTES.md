# C6-F4.2 Fixed Overlay

- Uses the real F1.1 `ChallengeMigrationAdapter.migrate_legacy_v1_to_v2(config, policy)` contract.
- Shadow runs after legacy autovetting and uses the effective `seed_used`.
- F3.1/F3.2/F3.3 are not modified.
- No runtime registration/mutation of `VideoProfileRegistry`; static file-backed shadow profiles are used.
- Shadow-only compatibility projection adds `generation` from `simulation` and maps the legacy temporal dictionary to a static profile ID.
- Equivalence gate compares fps, all phase frame counts, total frames, GAME-relative winning frame, simulation frame count, and full FrameSnapshot state including `custom_data`.
- Any mismatch exits before telemetry and Movie Maker.

This overlay is designed to be copied over the current C6-F3.x workspace. The archived D4 package available to this session predates the F3 execution/presentation files, so it is not used as though it were the current workspace.
