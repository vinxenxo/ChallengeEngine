# C11-D Exact-Selector Visual Loop Payload V2 — additive overlay

**Mode:** `ADD_ONLY`  
**Scope:** preparation-only, in-memory materialization for the five existing Geometric Waves selectors.  
**Runtime required:** Godot `4.7.1.stable.mono.official.a13da4feb` console build.

## What this increment adds

The existing Request-Scoped Grammar Parameter Binding V2 stage binds five request-specific, deterministic 20-field style-parameter instances. This overlay adds a second, separate in-memory stage which joins each instance to the frozen C11-C `VisualAuthoringGenerator` envelope, family variation recipe, resolved palette, and duration/frame-count metadata. Its ephemeral visual-spec descriptor carries the exact selected grammar ID and its style values. The shader-branch mapping appears only as review metadata.

The probe builds each selected candidate twice independently and requires matching canonical SHA-256 digests. The audit pins the frozen C11-C manifest first, verifies all direct source pins, invokes the existing parameter-binding audit, and then invokes the new Godot harness once for each canonical selector.

## What this does not do

- It does not change C11-C or simulation truth.
- It does not instantiate `GeometricWavesRenderer` or `ShaderMaterial`, execute a shader, or render a frame.
- It does not write payload/receipt files, images, or video, and emits no renderer-native input.
- It does not consume timing/review policy bodies; the nine references per selector remain metadata only.
- It does not approve this payload, make candidate input admissible, or open `D4.8`.
- It does not close authoring gaps for non-geometric families or other content types.

Expected permanent locks: `approvals_granted=0/19`, `candidate_input_admissible=false`, `renderer=OFF`, `media_created=false`, `D4.8=BLOCKED`, `release_authority=NONE`, `D9.10=PREPARE_ONLY`, `D9.17=BLOCKED_NO_GO`, and `D10=BLOCKED`.

## Projection conformance repair

This superseding repair overlay replaces only the exact-selector payload GDScript harness, its strict contract's harness hash, its tests and the related checkpoint/README. The failure was a logic mismatch between raw C11-C variation values and the already accepted normalized request-bound projection. The fix reuses the exact projection function from the parameter-matrix harness. It does not expand renderer scope or change any governance lock. Use `C11D_VISUAL_LOOP_EXACT_SELECTOR_PAYLOAD_V2_PROJECTION_FIX_OVERLAY_MANIFEST_20261016_V1.json` and its checkpoint as the active post-repair verification record; the original V2 overlay manifest remains an immutable record of the initial package.


## Bound-instance consumption repair V1

This superseding correction consumes the parent's cryptographically validated 20-field request-bound style instance as the payload's style source. It avoids an overly strict second Dictionary comparison across a JSON/Python/Godot boundary while preserving an exact key set, style digest, parent instance digest and numeric field-by-field re-derivation check. Genuine numeric mismatches are reported by field. The correction does not activate a renderer, write payload/media, change C11-C, or grant approvals.


## Float serialization tolerance repair V1

This superseding correction addresses tiny IEEE-754 numeric differences after style values cross the request/JSON/Godot boundary. It uses a strict absolute tolerance of 1.0e-10 only in the independent numeric projection comparison; discrepancies above that tolerance still fail with per-field diagnostics. The validated bound style dictionary, exact 20 keys, selector, style digest, instance digest and double-materialization deterministic digest remain required. No renderer/native input, shader execution, file payload, media, or approval path is enabled.
